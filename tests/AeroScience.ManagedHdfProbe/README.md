# Managed HDF/NetCDF storage candidate (research only)

This executable is excluded from AeroScience.sln and all application dependencies. It explores a
smaller alternative to the unapproved GDAL binary bundle. PureHDF **2.2.0** is MIT, has no NuGet
runtime dependencies, and incorporates translated C-Blosc2 shuffle code under BSD terms. Pinned
publisher notices are retained here; complete production notice/codec/security review remains a gate.
No app package/installer includes this probe or its dependency.

The extended `EmitWindowReader` prototype now tests a **strict synthetic metadata contract** across
V2 reflectance/uncertainty and a V3 mask, without requiring equal version digits. It checks companion
scene/acquisition identity, float32 dimensions/fill/units, wavelengths/FWHM, native swath lat/lon,
one-based GLT → original pixel mapping, zero/invalid GLT, variable-length mask names, original numeric
quality arrays and MSB-first packed band masks. Native swath coordinates and the geographic GLT cell
center are kept separate. It does not convert the swath into a fictitious north-up original raster.

Decompressed source chunks are rejected above **4 MiB** before sample reads; each dataset gets its own
bounded **256-KiB** chunk cache. A shared cache was found to alias chunks across reflectance/uncertainty
datasets during development; explicit independent-value assertions now prevent this. Sampling is
serialized, supports cancellation between bounded reads and never loads an entire cube. The test
also rejects a sparse six-MiB chunk without allocating its full declared spectral cube, mismatched
companions and invalid coordinates. **21** semantic assertions and 1,000 repeated spectra run alongside
the original storage assertions. All five new fixtures are marked synthetic and hash checked.

`generate_emit_fixture.py` uses developer-only netCDF-C, as the original generator does. The exact
experimental attributes (`scene_id`, `product_version`, CRS string, etc.) are **not** represented as
verified NASA header conventions. Version-specific original metadata/type/filter compatibility,
external-link/security review, authentic QA semantics, geolocation/uncertainty comparisons and
production download/import/Library/map/export integration remain open. Raw QA is returned without
inventing Good Data, certified accuracy or in-flight credit. No protected original was exercised.
Ordinary AeroScience users still have EMIT discovery only; this excluded project changes no app behavior.

The original **synthetic** 12-KiB fixture is real NetCDF-4 storage generated by netCDF-C. The managed
reader checks one 1×1×4 hyperslab through deflate/shuffle/Fletcher32, exact native fill, groups,
wavelength bytes/units and GLT index bytes. That storage test alone does **not** implement EMIT product semantics,
companion matching, QA/uncertainty/geolocation, geographic rendering or source import. Four synthetic
wavelengths are not NASA observations. Fixture provenance explicitly identifies that distinction.
The generator uses a development system library; the probe/installed .NET reader needs no Python or
native NetCDF library. Fixture checksum identifies the input; generator library versions may produce
different container bytes while preserving the intentionally synthetic values.
