# Recorded FAA public TFR originals

Downloaded from official FAA public reference services on 2026-10-24. See `receipts.json`
for exact URLs, retrieval UTC, length and SHA-256. FAA source attribution retained;
no credentials or private data. These original bytes are not converted across Git checkouts.
They are historical test inputs, not a current or complete airspace briefing.

`notice-*` is NOTAM 6/2070. The other packet filenames contain their exact NOTAM identity.
Both structured packet formats, including original UTF-16 AIXM, are preserved. See
`docs/research/v0.6.0-tfr-operations.md` for observed source limitations and validation classes.
