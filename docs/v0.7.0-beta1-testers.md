# AeroScience 0.7.0 Beta 1

Private tester build for Windows x64 and MSFS 2024. This beta has not completed
installed Windows/MSFS or scientific release acceptance. It is not the stable app.

1. Close AeroScience and MSFS. Run `AeroScience-Setup-v0.7.0-beta.1.exe`.
   Setup installs a separate Beta 1 application and Start menu shortcut. Windows
   may request administrator approval for Microsoft's Visual C++ prerequisite.
2. Launch **AeroScience 0.7.0 Beta 1** from the Start menu. The app and simulator
   toolbar identify themselves as **AeroScience 0.7.0 Validation**; Beta 1 uses
   that existing isolated testing profile and its source-matched toolbar.
3. With MSFS closed, use AeroScience Settings to install this build's matching
   validation toolbar. Keep the app folder intact. Then start MSFS and select
   **AeroScience 0.7.0 Validation** in its toolbar.
4. Start in **My Research**. Prepare a saved plan, record a flight and start science
   collection separately. Check the prominent science banner and interval Apply
   confirmation. After the flight, review terrain units, maps and elevation profiles.
5. Report what you expected, what happened, and a screenshot. Include the source
   commit from Connection & Build Details or the installed `BETA-BUILD.json` file.
   Avoid sharing credentials, personal flight databases or scientific libraries.

Stable data stays separate. This beta uses the existing v0.7.0 validation data
profile; if you already use that profile, back it up before testing. Do not select
stable or older validation data folders. Only one AeroScience companion can run at
a time. No accounts or scientific source datasets are bundled; source access and
downloads retain their existing consent and provenance requirements.

Missing terrain remains missing. Optional simulator terrain context is approximate
and separate from historical DEM science; it does not earn scientific credit.

Uninstall **AeroScience 0.7.0 Beta 1** through Windows Installed Apps. Its mission
history, scientific library, settings and validation toolbar are retained. Remove
the validation toolbar through AeroScience Settings before uninstalling if desired.
Stable installations and unrelated Community add-ons are preserved.
