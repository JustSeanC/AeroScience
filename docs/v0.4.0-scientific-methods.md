# v0.4.0 scientific methods and limits

## Independent times and sources

Flight and auxiliary observation timestamps are host UTC at receipt. Each optional weather/ground scalar and the existing atmospheric packet retain their own receipt times. An aircraft position associated with a cached value may differ by up to three seconds; no interpolation invents intermediate observations. Historical external scene observation time, publication time, retrieval time and processing time remain separate. Unknown source dates stay unknown.

The existing 360-byte aircraft, 40-byte atmosphere and 248-byte guidance definitions are unchanged. Nine independent FLOAT64 definitions request `GROUND ALTITUDE` (meters), `AMBIENT IN CLOUD` (bool), `ENV CLOUD DENSITY` (percent over 100), `AMBIENT VISIBILITY` (meters), `AMBIENT PRECIP RATE` (millimeters of water), `AMBIENT PRECIP STATE` (mask) and `AMBIENT WIND X/Y/Z` (meters per second). Each has an independent request/exception group; an unsupported scalar does not disable core recording or another scalar. No aircraft/autopilot writes are introduced.

The [official miscellaneous SimVars](https://docs.flightsimulator.com/msfs2024/html/6_Programming_APIs/SimVars/Miscellaneous_Variables.htm) specify cloud density as 0–1. Precipitation has no documented time denominator here: it is **not converted to mm/hour**. State mask bits 2/4/8 represent none/rain/snow; unknown bits are retained. Wind axes are described in source metadata, with no undocumented sign convention inferred. Missing, invalid, paused, stale and unsupported observations remain distinct. Connection/loading/aircraft changes clear auxiliary caches. Runtime support must still be tested against the installed SDK/simulator.

## Planning geometry

Horizontal calculations retain the existing WGS84 GeographicLib geodesics and canonical meters. MSL targets remain canonical feet. Aviation/Metric preferences convert the display without changing saved geometry. The assistant keeps AGL and groundspeed separately from MSL targets/IAS/TAS.

For a level nadir flat plane, cross-track swath is `2 × AGL × tan(horizontal FOV / 2)`. Track spacing is `swath × (1 − side overlap)`. Camera nominal GSD divides the corresponding footprint dimension by detector samples. Camera acquisition interval is `along-track footprint × (1 − forward overlap) / groundspeed`. Pushbroom along-track spacing is `groundspeed / selected line rate`. Ideal scanner density is `effective measurement rate / (swath × groundspeed)`. These are modeled values; turns, attitude, mounting, relief, line scanning, occlusion, QA and source resolution limit useful coverage. Durations exclude transit/climb/turns/pauses. Warnings disclose insufficient saved-acquisition cadence.

The assistant reuses polygon-clipped geodesic scan-line generation. Modeled strip previews are a level-flight baseline. Optional retained DEM/DSM planning intersects four mounted rays with a relative-AGL terrain surface, using 25 m slant steps and bounded bisection. It requires verified source files and adequate valid coverage; nodata/horizon/range errors disclose a flat fallback. Only the center footprint is terrain-aware; route strips retain their flat-baseline label. This does not implement full occlusion, align simulator MSL with an unknown vertical datum, or convert a DSM into bare-earth terrain.

## Atmospheric and terrain findings

Vertical Profile, Cloud Structure Survey and Atmospheric Transect plans record actual local simulator values. Direction/altitude intervals and maximum temporal gap are saved settings. Bins use distinct valid atmosphere packet times and selected ascent/descent/both direction; missing values do not contribute to means.

Local lapse is `−Δtemperature / ΔMSL-altitude × 1000 K/km`, requiring distinct valid packets and at least 1 m vertical separation. Negative lapse marks a **candidate local inversion**. Horizontal movement and changing simulator weather confound regional interpretation. Cloud entries/exits require contiguous valid 0→1/1→0 transitions; gaps, missing data and recordings already inside cloud leave boundaries unknown. Charts do not reconstruct 3D clouds or regional weather.

Along-track simulator surface slope is `atan2(Δground altitude, WGS84 distance)` across distinct ground packet times and at least 1 m horizontal travel. Clearance is independently reported simulator AGL. The simulator ground vertical reference is unspecified, so absolute comparisons to NAVD88/EGM/ellipsoidal terrain are not silently made. Raw recorded environment context can continue while optional Science Collection is paused; it is not relabeled as an instrument acquisition.

Cloud/precipitation/visibility/temperature-envelope cautions are qualitative. They do not invent quality percentages, override original satellite QA or replace missing observations.

## Spatial analysis and numerical exports

[Coverage/replay](v0.4.0-replay-and-coverage.md) and [composites](v0.4.0-scientific-composites.md) describe denominators, projection/error bounds, pixel support, native grids, processing limits and lineage. Display previews are explicitly separate from numeric products. The genuine-data reports distinguish synthetic flight inputs from actual external originals. No independent hardware calibration, Windows flight acceptance, worldwide data availability or scientific publication fitness is implied.
