## Design and implementation

The sequence is Plan → Prepare → Fly → Review → Understand → Compare → Export.
The shared vanilla-JavaScript/CSS components provide consistent typography, spacing,
44px controls, named page headings, visible focus, status/error/retry components,
readable byte sizes, accessible paged tables, scientific legends and charts. This
extends existing recording/science/storage services without a framework rewrite.
See [design rationale](v0.4.2-ux-design.md) and [source audit](v0.4.2-ui-audit.md).

| Area | Result |
|---|---|
| Science Map / UX-AD01 | All saved categories are represented together, including atmospheric values; independent instrument toggles and compatible quantity defaults; dates, units, provenance and explicit warnings |
| Whole archive / UX-AD02 | Full selected indexed scope automatically traversed with bounded keyset pages; no former 120-acquisition ceiling or manual 500-value loading action; viewport aggregation and exact-record browser/search |
| Counts | Distinct acquisitions, geolocated simulator fields, viewport records, overview features and currently loaded native cells/values; repeated samples do not imply unique area |
| Scientific presentation | Viridis scalar colors, constant-value legends, stated RGB stretch, compatible shared numeric scales, transparent gaps, opacity for native vectors and derived images |
| Comparison | Two primary dataset cards, supported visual quantities, synchronized geography/location inspection, current-mission links, independent/shared scales, exact matched-cell B−A map/statistics/chart/table; incompatible subtraction remains refused |
| Analysis | Instrument-specific findings, actual statistics/charts/maps, source dates/datums, quality, environmental profiles and actual transect tables; technical evidence remains disclosed |
| Mission Control | Recording/connection/selected mission/essential telemetry primary; optional attitude/profile/environment/guidance/notes remain available under disclosed flight details/tools |
| Downloads | Full-page activity plus optional quick status; readable names, truthful concurrent/partial states, unknown ETA, stable rows/focus, scoped controls and diagnostic export |
| Library / History | Reusable-source collection search/category/provider/sort, coverage and precise sizes; offline archive sorting, scientific status and direct review/replay; original files/settings preserved |
| Help | Task search, contextual rendered offline guides, GitHub, optional Discord and existing feedback/log collection |
| Navigation / accessibility | Labeled tablet drawer, Escape/focus restoration, skip navigation, reduced motion, non-map scientific and waypoint inspection, chart values tables, readable responsive layouts |

## Performance

The [defined synthetic benchmark](v0.4.2-performance.md) and
[machine-readable measurement](research/v0.4.2-browser-performance.json) cover 2,100
acquisitions and 12,000 environmental values. Local overview load was about 1.4s and
layer feedback below 200ms in the recorded run, with bounded features/table rows and
explicit V8 memory measurement. This is repeated small native support, not thousands
of large unique satellite scenes or a long live flight. Server metadata work remains
linear in selected record count; very large archives should use narrower scopes.
