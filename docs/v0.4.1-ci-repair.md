## Root causes and changes

| Failure | Cause | Repair |
|---|---|---|
| Linux missing recovery DLL | Smoke script's inferred conventional path was not the host output built by CI | Explicitly build the restored TestHost project into `artifacts/recovery-test-host`, then pass that exact DLL to the real crash/restart smoke test. |
| Migration test: no `remote_products` | Several valid schema-1 backups exist; the earliest precedes the remote-products extension. Filesystem enumeration can present it first. The test predicate queried the newer table in every older backup. | Check table existence before the payload predicate; retain integrity checks and require a backup containing the exact original remote product. Original mission/science payload assertions remain. |
| Four-instrument cadence timeout | Repeated delays accumulated scheduling jitter. The first hosted Windows rerun also demonstrated real queue drops under competing physical-I/O test load (multispectral 6/10, rather than an undrained successful queue). | Use anchored packet UTC; preserve 1 Hz, ten packets, ≥36 products and 9–10 per instrument. Reuse existing datasets. Move this I/O-sensitive test into an isolated collection so unrelated fixture traffic does not act as an unspecified hardware benchmark; its four production acquisition workers still run concurrently. Hosted Windows revalidation is required. |
| Blocked-output timeout | A wall-clock fixture deadline released output while durable recording was still progressing. In the first Windows rerun the 60-second deadline released it before the ~74-second test finished, causing the test's own blocked-writer assertion to fail. | Use a five-second progress watchdog for each of 120 packets, keeping output blocked until recording completes; retain exact packet/observation/gap assertions and release/join tasks in finally. This tests lock independence rather than requiring a 120-packet burst to finish in an arbitrary bulk deadline. |
| `engine.lock` cleanup | Pure configuration tests unnecessarily started a server, then raced the deferred host lifetime. Async provider disposal alone was insufficient on the next Windows rerun. | Move address/pairing validation to a fixture-free class; await health/ApplicationStarted for actual API tests, observe ApplicationStopped, await provider disposal and reacquire the exclusive lease before cleanup. A new lifecycle regression asserts ownership while running and release during teardown. No lock bypass, directory-delete retry or ignored IOException. |

a newer run cancels its superseded predecessor. Linux/Windows build, locked restore,

remain. Structural fixture installers are never executed or published.
