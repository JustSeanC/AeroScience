# SAA geometry adapter 4 — supported subset

FAA aviation reference for simulation, not activation or flight clearance. Existing aviation
originals, schema-5 storage, STRtree index, viewport API and Leaflet layers are reused.

The reviewed source is FAA NASR 2026-10-01 `aixm5.0.zip`, SHA-256
`5bd6c9221ec61d1a9af22b18fe4d59d9378d2c38859d9c1a3619c26ff00b657b`.
Original files remain immutable. The new parser identity retains earlier literal/circle/arc
interpretations beside adapter 4. No redownload is needed to explicitly reimport an original.

## Supported construction

- GML CRS84 is longitude/latitude. The bundled FAA GML `AngleType` has no single-revolution
  restriction. Adapter 4 accepts an **explicit positive end-minus-start span up to 180 degrees**,
  including source angles outside ±360 degrees. Only the initial equivalent bearing is reduced;
  a negative delta is never normalized into a convenient positive arc. The inherited first-axis
  convention and GeographicLib WGS84 geodesics are unchanged.
- Curved segments retain their original centers, radii, units, angles and literal endpoints in XML.
  Interpolation retains the existing nominal 0.5 m chord target and maximum 0.5 m source join.
  Every join is checked before alignment. Literal points take precedence; an adjacent derived
  arc starts at the preceding computed end. No literal coordinate is replaced or gap repaired.
- `operationSequence` is the source-defined aggregation order (FAA's bundled
  `AIXM_Features.xsd`, `AirspaceGeometryComponentPropertyGroup`). XML order is not operation
  order. Require unique sequences, exactly one first BASE, and only UNION or SUBTR thereafter.
- Every component must have one inline, verified CRS84 surface and identical **original** known
  lower/upper value, unit and datum strings. There is no altitude conversion or inference of
  volume equivalence. NTS union/difference constructs horizontal multipart polygons, holes and
  islands within holes. Empty/invalid results fail closed; no buffer or topology repair occurs.
- `GEOMETRY_COMPOSITION` identifies a derived horizontal interpretation. `SOURCE_COMPONENTS`
  records original component ordinal, official volume/surface ID when present (otherwise null),
  operation/sequence, CRS and native limits. Immutable XML retains full original geometry;
  generated intersections/interpolation are never described as original literal vertices.

Limits remain Unknown when unsupported. Different/unknown vertical volumes, contributors,
external references, inferred angle wraps, negative/major spans, ambiguous orientation, bad joins,
non-CRS84/overridden axes, dateline/polar cases and invalid topology remain explicit omissions.
SAA working hours/activation fields are retained verbatim; no live activity is established.

## Bounds and interruption

Existing archive checks, 1 MiB XML/depth-64 guards and one-writer transactions remain. Each
construction has at most 32 components, 12,000 total input/result vertices and a four-million
vertex-pair bound before synchronous NTS Boolean work. Recording/cancellation checks occur
through reads and before/after operations; a failed publication rolls back the whole dataset.
These per-operation bounds do not impose a retained Library collection limit. Existing viewport
limits and separate full/source versus simplified display geometry are preserved.

## Reproduction and evidence

Use a new isolated copy of retained aviation evidence, never edit prior source records:

```text
dotnet run --project tests/AeroScience.TestHost -c Release -- --airspace-reference-probe offline <evidence-copy>
python scripts/research/verify_airspace_originals.py --folder <evidence-copy> --adapter 4 --output <new-result.json>
```

The independent developer environment needs pyproj, Shapely and pyshp; these are not product
runtime dependencies. `--adapter 3` explicitly checks the historical minor-arc interpretation.
The verifier selects the exact source/version-derived dataset ID, checks original hashes,
reconstructs PROJ arc samples and GEOS Boolean geometry, checks component identities/limits,
retains strict literal equality and the existing `1e-10` degree interpolation tolerance, and
accounts for every source record. The application probe captures per-record omission identities
and reasons, indexed east/west queries and historical WKB/payload hashes before/after reimport.

Initial genuine comparison: SAA **990 supported / 246 omitted**, versus **979 / 257**;
57,936 coordinate components and 18,904 fields checked. Eight unwrapped-angle records and
three subtractions are recovered across Alaska, Florida, Georgia, Hawaii, Idaho, Michigan,
Montana, North Dakota and Texas. Same-volume unions/nested islands are tested synthetically;
the retained FAA edition's union components have different vertical limits. Do not label those
synthetic tests as genuine union acceptance. Class B/C/D/E remains unchanged (5,610 / 2).

See the [current tracker](../roadmap/v0.6.0-development-tracker.md#saa-3a--bounded-supported-geometry-expansion-2026-10-24)
for final source, independent results, CI and limitations. Physical Windows/MSFS/iPad/Quest and
live operational acceptance are separate. Signed/major arc interpretation and unequal-volume
relationships remain further work; no guessed shape is indexed to improve the count.

## Adapter 5 — separate native vertical volumes

The additive metadata contract (version 2, existing aviation schema 5) retains ordered inline
BASE/UNION/SUBTR components with their own geometry, official IDs, raw altitude values/units/
references and nullable inclusivity. Different or unknown limits are **not flattened**. Original
WKB is an ordered GeometryCollection; display/index geometry is the conservative union of BASE
and UNION footprints. SUBTR changes membership only inside its own horizontal and vertical
component. A potential map extent is therefore not a restriction volume or valid activation claim.
Historical adapters, originals and schema remain unchanged.

The existing reference dialog exposes each component outline and an explicit point/altitude
advisory. Three-valued set algebra preserves uncertainty: MSL, surface-relative and standard
pressure are comparable only to the same known reference; feet/metres and pressure flight levels
use exact documented unit conversion. Missing pressure/terrain conversions and boundary
inclusivity stay Unknown. Explicit UNL is distinct from sentinel/missing limits. Published H24,
working hours, DST and source offsets remain published facts, not live activation or inferred UTC
schedules. This read-only assessment neither fetches FAA data nor blocks any flight controls.

Genuine 2026-10-01 replay: **990 → 1,098 supported; 246 → 138 omitted**. The 108 newly retained
native models comprise 95 known different-limit models and 13 with at least one unknown limit;
108 BASE, 168 SUBTR and 50 UNION components. Independent ElementTree/PROJ/Shapely verification
checks component order, native altitude definitions, exact literal coordinates, unchanged
`1e-10` degree curve tolerance and conservative display union. Original member identity remains in
metadata/XML. Linked contributors, ambiguous curves/joins and invalid topology remain omitted.
See [new evidence](v0.6.0-saa-3b-validation.json); prior evidence is retained unchanged.
