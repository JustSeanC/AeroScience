# Personal template sharing

Open **My Research**. **My Templates** provides **Create Template**, **Import Template**
and **Clone Built-in Template**. Your saved cards also have **Clone Template**,
**Export Template** and **Propose to Organization**. The existing **Edit Card**,
**Guided Builder**, **Advanced Editor**, **Fly Now** and Mission Planner remain the
edit and flight paths. No account or internet connection is needed for personal use.

## Export, import and clone

Choose **Export Template**, select a **Saved revision**, optionally add a description
and declared attribution, then choose **Review Template** and **Download Template**.
The `.aeroresearch.json` file contains only a reusable definition and its limitations.
It does not contain flights, attempts, results, science files, claims or credentials.

Choose **Import Template**, pick the file and read its question, instruments,
quantitative requirements and limitations. Enter a **New personal template name**
and choose **Save as Personal Template**. This creates a new independent card.
Unknown fields, future versions and invalid criteria are refused without changing
the file. **Clone Template** and **Clone Built-in Template** similarly create an
independent editable copy without copying attempts or organization authorization.

Supported definitions include flight regimes, custom single-point tests, multi-point
procedures with AND/OR, order and repetitions, atmospheric profiles and transects,
terrain/temperature surveys, pilot observations and the modeled temperature sensor.
Imported criteria use the same validators and evaluators as locally authored cards.
Self-declared attribution is not authenticated authorship or scientific approval.

## Propose a definition

Choose **Propose to Organization**, select the exact revision and choose
**Review Template**, then **Choose Organization**. Open **Review Proposal at …** for
the intended connected organization. The definition is carried in a browser fragment;
no evidence is uploaded. Sign in on that organization's page, review the destination,
**Proposed template name**, purpose and definition, tick the approval checkbox and
choose **Submit Proposal**.

**My Template Proposals** shows your status and **Proposal History**. A manager may
request changes, reject with an explanation or accept an independent organization
draft. A revised file requires another preview and explicit resubmission. Proposing
does not grant the desktop new permissions: Read Published, Manage Own Claims and
Submit Evidence retain their existing boundaries. Different organizations require
separate previews, browser authorizations and proposals.

## What sharing means

A definition is not proof that a flight occurred, a hypothesis is true, an instrument
was calibrated or an aircraft was certified. A modeled sensor remains a fictional
documented response to original simulator inputs. DEM and Landsat requirements remain
historical-source dependencies, never bundled datasets or new airborne measurements.
Importing a file does not authorize downloads, network access, uploads or retroactive
organization credit. Missing evidence, source QA and existing deletion rules remain
unchanged.

The technical format and migration decision are documented in
[Personal templates and publication governance](architecture/personal-template-portability.md).
