# v0.4.2 baseline audit

Baseline: `2627164`, v0.4.1 source. The approximately 5.9/10 external preliminary
assessment is not a measured per-category baseline. Category scores are unknown.

| Area | Confirmed source finding | Required correction / evidence |
|---|---|---|
| Map opacity | Handler only calls vector `setStyle`; composite images are outside that group | One scientific-layer controller for vectors, imagery and observations; test image opacity |
| Map counts | Acquisitions accumulate but valid cells reset per returned page | Cumulative, explicitly named loaded acquisitions/cell instances; separate unique locations |
| Constant scale | Min=max still renders blue→red range | Single-value legend and one color; regression |
| Initial map | All-scope defaults to elevation regardless of available instrument; atmosphere is a manual secondary path | Infer supported layer from actual saved products; load recorded atmosphere automatically |
| Compare | Each map independently normalizes; analysis URL constructed once after first load | Explicit independent/shared legends and current-selection actions; actual common-cell delta |
| Analysis | Generic four KPIs and paragraphs precede instrument visualizations | Instrument findings, actual numeric graphics and accessible tables first |
| Downloads | Modal only; kind codes used as names; ready+active states collapsed | Dedicated route, readable names and concurrent-state summaries |
| Library | Metadata-heavy summary text; MiB rounded to zero; no category/provider/sort | Collection cards, precise human-readable bytes and controls |
| Tablet | 80px sidebar/font-size:0 rules rely on icon spans missing from several links | Labeled drawer; no microscopic typography |
| Accessibility | Native-cell inspection only via path click; no axe coverage | Equivalent keyboard observation table, focus tests and axe audit |
| Control | Secondary environment/guidance/notes panels append at full size | Keep recorder/route/essential telemetry primary; disclose secondary sections |
| Help | Guide tabs only, no task discovery | Searchable task index and contextual help with offline guides |

The [completion report](v0.4.2-completion.md) links before/after evidence, measured
performance and resolved findings from actual browser evaluation. Do not interpret this inventory as a completed audit
of screen readers, physical devices, simulator input or representative human usability.
