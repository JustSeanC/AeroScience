## Scientific review rules

Science Map displays QA-valid native cells containing saved mission samples, not an
unflown source scene masquerading as aircraft acquisition. A displayed source cell
describes spatial support, not proof every part was sensed. Antimeridian-spanning
single display cells are excluded with an explanation; numeric exports remain available.
Different physical quantities, native wavelengths or vertical datums do not share a
false numeric color scale. Native composites reuse the existing scientific algorithms.

Comparison uses shared valid native pixels only, matching grids, units, source kind,
configuration and datums. Unknown observation dates and unsupported quantities receive
an explicit arithmetic refusal. Revisiting one historical scene is not Earth change.
Atmospheric interpretation uses distinct actual packets, minimum sample/altitude span
and stated descriptive correlation rules, without inferring causation.

Recovery uses exact committed position/time/configuration evidence from scheduled
attempts. The original flight and in-flight products remain immutable. Pending science
is provisional in full-page review and research ZIP metadata. New derived artifacts
have identities tied to actual product hashes; earlier files/exports remain identifiable
and are not silently rewritten. Legacy archives receive no invented recovery backlog.

## Genuine-source evidence

[Retained-source review](research/v0.4.1-retained-review-acceptance.json) records a
current-source run against genuine retained USGS terrain, Landsat surface-temperature
and Sentinel-2 observations, with synthetic scheduled flight positions explicitly
identified. Discovery/download occurred in the earlier development benchmark; this
review made no new provider requests. Each workflow records exact source file hashes,
separate source/flight/processing dates, an idempotent reconstructed product, spatial
query, summary and native composite.

An independent rasterio/GDAL oracle checks original hashes, affine/CRS, sample locations,
native scaling, Landsat masks, Sentinel SCL/NDVI, nodata support and per-instrument sample
counts (without double-counting terrain's native/derived alias). All three kinds match
within 1e-9. Terrain's source observation timestamp remains unknown when the provider
does not supply it; none is invented. No hyperspectral pass is implied.

[Concurrency experiment](research/v0.4.1-concurrency-acceptance.json) preserves actual
bytes/time/resources and failed counts. It predates the final source freeze and is not
relabeled final-source acceptance.

bytes. A separate Sentinel retry discovered the genuine scene and transferred 816,248
bytes before a required exact range returned HTTP 503. Partial data was refused, with
