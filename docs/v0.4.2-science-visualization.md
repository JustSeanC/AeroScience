# Understand your scientific map

## Overview and exact values

All instruments shows separate scientific categories. Location clusters summarize all
indexed acquisitions and geolocated simulator values in the selected scope. They are
an overview, not continuous imagery or a scientific value measured at a cluster center.
Zooming updates the geographic query. The archive browser can open any saved record,
including overlapping acquisitions at one location; its page number has no former
120-acquisition viewing ceiling. Search recorded metadata, UTC, quality or environmental
values across the selected scope; search is a literal match in saved metadata, not
a numeric range query or a scan of every retained source raster.

Native colored cells contain actual saved valid sample support. A full-cell display
does not prove the aircraft sensed every part of that cell. Retained source imagery,
modeled footprints, recorded atmospheric packets and derived mission imagery are
different representations and are labeled separately.

## Counts and missing data

Acquisitions are saved instrument capture records. Simulator values are individual
environmental fields; multiple fields can share a timestamp. Saved sample positions
can repeat across captures. Native cell records are the pixel supports currently loaded
for detail. None of those counts is automatically a geographic area percentage.

The overview counts the complete selected indexed scope. The map reports separately
what falls inside the visible region and how much detailed data is currently loaded.
Layer choices, opacity and the viewport are restored when returning within the
same browser session. Large scopes use aggregated locations; zoom or the archive browser exposes actual
values without drawing every measurement at once.

Transparent areas may be outside sampled support, unqueried, cloud-masked or nodata.
They are not zero measurements and are never filled with invented science. A source
catalog envelope and a modeled sensor footprint do not establish valid-pixel coverage.

## Legends and source dates

Scalar legends show actual units and numeric endpoints. A constant dataset uses one
color and a constant-value label. Natural/false-color imagery uses its stated
reflectance display stretch; the numeric source values remain unchanged.

Instrument layers keep independent units, wavelength and vertical-reference context.
The inspector and recorded-values table expose flight time, historical source date,
quality and provenance. An unknown source date stays unknown.

## Compare two datasets

Dataset A and B keep their own mission, instrument and source date. Shared color scales
are available only for matching physical quantities. Otherwise independent legends
remain visible. Selecting a location checks actual corresponding saved cells; it does
not substitute a nearby value or interpolate across a gap.

Numeric differences require compatible units, native grids, source capabilities,
wavelengths, vertical references and archived settings, as well as common valid native
cells. The signed difference is compared dataset minus Dataset A. Different source
dates remain descriptive; they do not establish causation. Repeated simulator visits
to one historical scene are not independent observations of Earth change.

## Accessible inspection

Every plotted result has a keyboard-accessible recorded-values alternative. Choose an
acquisition or observation in the archive browser, inspect its table, and use the
linked analysis/export actions. Numeric legends and tables supplement color graphics.
Actual screen-reader and physical iPad usability require separate acceptance testing.
