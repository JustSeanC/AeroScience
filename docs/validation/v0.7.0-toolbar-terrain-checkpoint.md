## Implemented changes and causes

**#27 — collection status and text.** A large text/color banner stays above the
scrolling Mission, Payload, Map and Research pages. ACTIVE requires fresh,
mission-matching authoritative Collecting state with a real session and no
collection/storage fault. Armed, paused, ended, stale and disconnected states are
inactive. Recording and collection remain separate; the banner does not certify
measurement quality. The old default view buried collection state below research
details. Generated receipt strings still supplied middle-dot separators after the
earlier static-label correction. Native presentation now converts generated
decorative punctuation while preserving exact known Unicode names and original
stored scientific text/units. Native font acceptance remains an MSFS check.

**#28 — interval editing.** The old polling render assigned the confirmed interval
whenever the select was not `document.activeElement`. A selection could therefore
be restored before the native dropdown completed its interaction. A controlled
lost-focus browser case reproduces this source defect: the compiled baseline
returns a 5-second selection to 1 second while its instrument command is still
pending. Precise Coherent event
routing remains unverified. The control now keeps a draft independently of focus,
uses an explicit Apply interval action, and reports the engine acknowledgement or
refusal. Pre-acknowledgement polls cannot restore an old selection. Delivery failure
and timeout preserve a reviewable draft; Use confirmed interval cancels it.
The six existing quick choices remain. Other backend-supported values retained by
the dashboard remain visible as confirmed values. Commands are flight-bound.
The old backend also reset every acquisition schedule and remote worker generation
for any configuration change. Only the changed instrument is reset now; other
instrument cadence, session identity and saved observations remain intact.

**#29 — terrain display and profiles.** Elevation presentation follows the saved
science Altitude preference, independently of PlanningProfile. Preview values and
display PNG/CSV, Science Map inspection/tables/legends, derived-map legends,
statistics and profile charts update live in feet or meters. Canonical source
meters, hashes, vertical references and scientific exports remain authoritative.
Unknown reference is never relabeled MSL.

Terrain acquisitions use one bounded canvas per loaded acquisition, drawing only
the exact QA-valid native cells returned by the existing geographic science API.
This removes thousands of DOM polygon paths and their default outlines. Opacity,
the common compatible-source color scale, click inspection, accessible values and
explicit native-cell outlines remain available. Missing cells stay transparent;
the rendering does not fill acquisition envelopes or create verified coverage.

Elevation Profile lives within Science Map and replaces the acquisition preview's
sample-index center-row chart with a link to the shared route profile. It samples
one explicitly selected, integrity-verified retained affine DEM/DSM along a real
recorded track/UTC segment, saved route/leg, or drawn/keyboard-entered A–B line.
The x-axis uses cumulative WGS84 geodesic distance, not sample index. The chart
provides min/max/net where supported, tooltips, a linked map cursor, keyboard
location inspection and display PNG/CSV. Source dates, resolution, datum, gaps and
method are disclosed. This is read-only source analysis, not extra collected
science or proof of airborne coverage.

Optional **MSFS Terrain - Simulated Context** uses only actual retained simulator
MSL-minus-AGL telemetry. It is off by default, sparse, approximate, separately
labeled and drawn as points. It never fills the DEM series, enters official
scientific exports, or changes yield, coverage, quality, grading or research-card
success. Existing SimConnect telemetry already contains these two heights; no
arbitrary-location terrain API or new simulator acquisition was invented.

## Deliberate limits

- One DEM/DSM source per profile; incompatible references are not blended. No
  vertical-datum transformation or claim that DSM equals bare earth.
- At most 2,049 samples and 100,000 original track positions per request. Choose a
  shorter segment for finer detail. Original nearest pixels are used; disconnected
  or coarsely spaced support is not joined. Known flight gaps remain gaps and
  explicitly qualify the distance measurement. No contours or hillshade added.
- Original-source analysis yields while a flight is recording. Missing, changed,
  deleted or unsupported sources fail explicitly rather than inventing elevations.
- The flight/plan pickers show recent pages plus the selected archived flight and
  its recorded route snapshot. Older saved plan routes can be selected through an
  appropriate recorded flight snapshot. No new primary navigation or preferences.
- Canvas rendering is bounded by the existing viewport/acquisition paging. The
  density test is a synthetic 3,805-cell load case, not external science evidence.
- Browser and mocked SDK transport evidence do not establish actual MSFS input,
  glyph rendering, panel behavior or genuine SDK packaging acceptance.
