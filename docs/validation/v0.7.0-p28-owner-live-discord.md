# P28 — Share a flight and try Discord

**Later tests, not yet performed.** Use a working test organization. For the map, ask one invited pilot to join. For Discord, an administrator needs a private test channel and its incoming webhook. Do not paste the webhook into chat or screenshots.

| Do this | You should see | Result |
| --- | --- | --- |
| Both pilots start recording. In **My Research → Organizations**, each chooses **Share Live Flight** and reviews the consent. | Only consenting flights appear in the organization's **Live Flights**. Discord receives nothing from member-only sharing. | ☐ Pass ☐ Problem |
| On one aircraft choose **Stop Sharing**. Briefly close the other pilot's AeroScience. | The first position disappears; the disconnected position expires. Flight recording is independent of sharing. | ☐ Pass ☐ Problem |
| As administrator, open **Organization Settings → Notifications**. Add the test webhook, review the settings, and choose **Send Test Notification**. | The private Discord channel receives the test. Delivery history reports **Delivered**, with no visible reusable webhook secret. | ☐ Pass ☐ Problem |
| Enable flight announcements. On a newly shared flight, open **My Discord Announcements** and choose **Allow Discord Announcements for This Flight**. | A concise announcement appears in the disclosed channel. It contains no coordinates, track, private notes or scientific samples. | ☐ Pass ☐ Problem |
| Choose **Revoke Discord Announcements**, then stop sharing that flight. | No new unsent announcement is released under the revoked consent. An already delivered message can remain in Discord. | ☐ Pass ☐ Problem |
| For approved research, use **Review External Announcements**, review the exact message and choose **Approve External Announcement**. | Only the explicitly disclosed approved summary appears. An attempt, receipt or members-only approval does not automatically post. | ☐ Pass ☐ Problem |

Problem? Stop. Send one screenshot or sentence, with webhook addresses and credentials hidden. Engineering investigates delivery and expiry.
