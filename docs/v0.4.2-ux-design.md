# v0.4.2 workstation design

Status: implemented design; no usability score, device acceptance or release approval.

## Audit and principles

The starting source is v0.4.1 plus the owner's `2627164` Sentinel-2 documentation
correction. That correction is retained. The full assignment is preserved in the
roadmap. No new UI framework, provider, instrument or calibration system is needed.

The primary sequence is **Plan → Prepare → Fly → Review → Understand → Compare → Export**.
Each page gets one task, a stable heading, a primary next action, a concise status,
and advanced details. Use the existing server-owned mission selection, acquisition
identity, scientific queries, native grids, composites and exports.

## Shared design

Dark workstation identity, readable 16px ordinary text, 14px supporting text, tabular
numerals, consistent spacing and 44px controls. Full labeled sidebar on wide screens;
an explicitly opened, keyboard-operable navigation drawer on tablet/narrow screens.
Do not compress text to keep a desktop sidebar. Use named landmarks, visible focus,
skip navigation, focus restoration, reduced motion and selective status announcements.
Native dialogs keep Escape/cancel behavior and restore their launch control.

Use accessible native controls and reusable DOM helpers. Separate scientific map,
comparison and analysis rendering into modules instead of extending the existing
137-line, densely coupled workspace file. State/readiness text accompanies colors.
Use a perceptually ordered scalar ramp, explicit measured NDVI ranges, and a single
color for constant values. Missing values remain absent/transparent.

## Page structures / wireframes

| Page | First screen | Secondary / advanced |
|---|---|---|
| Control | Connection, selected mission, Start/End, route, essential telemetry | Flight details, environment, notes and diagnostics |
| Science Map | Mission/layer, large map, numeric legend, coverage counts, inspector | Dates/source filters, bounded paging, manual derived products, methodology |
| Compare | Dataset A/B, aligned maps, dates, independent/shared scale state | Additional acquisitions, compatible delta layer/table, source evidence |
| Analysis | Mission header, instrument-specific findings, actual charts/maps | Packet tables, source identities, descriptive trend qualifications |
| Downloads | Mission preparation, instrument readiness and concurrent work | Regions, provider details, allowance/reservations, diagnostic export |
| Library | Search/category/provider/sort, readable collection cards | Region pages, geographic coverage, immutable provenance |
| History | Search/filter/sort, flight and science status, direct Review/Replay | Legacy archive details |
| Results | Scientific review status, clear export choices and source dates | Exact counts, provenance and native-product tools |
| Help | Task questions, search, readable offline guide | Detailed methodology, GitHub, optional Discord and feedback collection |

Map desktop layout: flexible map canvas with a compact layer/legend strip and an
adjacent inspector; inspector stacks below on narrow screens. A paged observation
table offers the same values/units/dates without using a map. Initial saved data loads
automatically. No navigation initiates external scientific downloads. Derived jobs
use existing bounded server workers and remain distinct from loading saved data.

Compare defaults to two columns. Shared scales require matching physical quantities,
units, wavelengths and datum; arithmetic additionally requires the server's full
scientific compatibility decision. Differences use actual common native cells only,
with coverage and source-date limitations. Every action uses the current mission.

## Validation plan

Retain scientific and archive regressions. Add functional Playwright coverage, axe
checks, keyboard/focus tests, map-table equivalence, scales/opacity/paging regression,
responsive interaction at 1920/1440/1280/1024/820/768/390px and zoom/reflow checks.
Capture all ten before/after views using explicitly labeled synthetic browser inputs;
inspect screenshots and fix issues. Measure defined large fixtures and report their
limits. Recheck genuine retained and online data without relabeling synthetic fixtures.

Use ISO 9241-11/210 task effectiveness/efficiency/satisfaction, Nielsen's heuristics,
WCAG 2.2 AA and Fluent 2 interaction conventions as review references. Automated
accessibility results are not WCAG conformance. Representative users, screen readers,
physical iPad Safari, installed Windows/MSFS and Quest 3 remain separate acceptance.
The weighted rubric and 90% independent task-completion target require evidence;
neither a 9/10 score nor a human study is assumed. v0.5.0 remains Advanced Instrument
Calibration & Aircraft Operating Constraints. No release or issues are published.
