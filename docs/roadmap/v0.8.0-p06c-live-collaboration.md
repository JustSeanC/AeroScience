After the server confirms sharing, the local status shows the actual consent expiry; the optional null-omitted status field does not change older status messages or evidence contracts. A disabled server policy keeps Start Sharing disabled, including after a failed start.

Joining, claiming, recording, collecting science and submitting evidence remain independent of live consent. Stop Sharing leaves recording/science intact. The existing relay clears expired/revoked positions and never restores old sharing after restart. No local telemetry history, route extrapolation, replay, source file, private mission name or private note is added.

The shared live UI identifies aircraft in the list and reports duration **at the last original source update**, using only the shared flight start and source timestamp. Missing, invalid, pre-start or expired source data gives Unavailable. Duration is neither recording continuity nor collection time. A paused scientific phase is explained separately. Existing cards/issued revisions, phase/source/UTC, units, graticule map, keyboard selection and conservative freshness behavior remain unchanged: stale at 15 seconds, position/detail clearing at 30 seconds, including a stalled/delayed HTTP response. A live position never supplies scientific evidence or approved campaign progress.
