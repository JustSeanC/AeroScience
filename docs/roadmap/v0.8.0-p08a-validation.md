## Adapted implementation

Provider parsing recognizes its existing retained `scene`/canonical-band envelope without rewriting metadata or changing source revisions. Required field types, finite scale/offset, QA masks, nodata, source host and unsigned asset identity remain checked. Bounded discovery can skip malformed candidates and find a later valid scene; optional catalog-display fields can be unknown. Missing cloud quality is not assumed clear. Exact selected-scene revision mismatch remains a refusal.

Mission preparation adds explicit `retry`, separately from resume/continue. Terminal failures survive restart; retry selects eligible failed/unavailable approved regions, preserves independent user/post-flight/stale-plan holds, and does not reset consent, allowance or storage accounting. Ready originals are reverified/reused. Empty or selected-key retry does not discard unrelated failures or allowance-wait tickets. The scheduler excludes a key still in execution cleanup. Existing Library retry remains unchanged.

Shared scientific HTTP received-byte counters gain a process identity, monotonic elapsed time and active body-reader leases. Numeric, catalog, NASA and public EPT paths use those same counters; cache reuse and local processing do not contribute bytes. NASA checkpoint flushing follows reader release. Recent UI rates use bounded 15-second/32-sample windows, reset for process/counter/attempt changes, suppress local processing, and expire stopped/stale measurements. Unknown-size numeric work retains unknown ETA. Existing main/Quick-status polling remains 3/2 seconds; a local presentation timer expires labels without additional requests. Existing known-original Library progress and all P05 terrain/point processing remain in charge.

The legacy Science Map compares its final viewport after initial loading and refreshes when necessary. Overview zoom describes the query actually issued. Existing bounded acquisition bins gain unfilled dashed extents with explicit modeled/unknown-support explanations. Native raster values, masks, source dates/hashes and the independent P05d Results maps are unchanged.
