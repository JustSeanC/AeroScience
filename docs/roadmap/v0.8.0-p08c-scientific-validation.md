## Runner and evidence contract

[`p08c.py`](../../scripts/validation/p08c.py) inventories explicitly selected retained inputs, rejects missing license/access context and mismatched expected hashes, and refuses existing attempt directories or linked paths. It invokes the existing TestHost's `TerrainElevationProbe`/`LidarProbe` offline paths, then the existing independent GDAL/OGR or laspy/lazrs/PROJ/GEOS oracle. It neither authorizes network work nor reads the owner's Library.

The pre-execution plan freezes source/build hashes and tolerances. Versioned receipts retain exact input hashes, actual DLL/native-helper hashes, output hashes, reference tools/results and failures. A failed process retains its log and a Failed receipt; it cannot silently become Passed. `verify` rechecks the plan, reference artifact and all retained artifact hashes. It verifies bytes, not human qualifications or public release authorization. The current small probes are deliberately restricted to their known originals because their provider labels and flight locations are specific; arbitrary originals must not inherit those claims.

Declared tolerances precede execution: native raster values and raw point coordinates/attributes exact; raster centers below `1e-12°`; native mask area/fraction differences below `1e-7` pixel units; independent point geographic differences below `1e-10°`; scan-angle differences below `1e-12°`; exact point membership/support. These are numerical comparison tolerances, not source accuracy certifications. No tolerance was adjusted after observing a result.

Focused regressions preserve actual geometry masks/holes, QA/nodata/scale/offset, separate sessions/references, stale identities, unsupported transforms/COPC, source-owned deletion, evidence and original science credit. Genuine inputs provide narrow numerical evidence; synthetic edge fixtures remain explicitly synthetic. Historical products award no acquisitions, grades, cards or organization approval.
