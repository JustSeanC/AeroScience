## Fixed decisions and preservation contract

Use **Auto** dashboard theme with optional user override, **guided** first-time flow, **balanced** density and initial **en-US, es-ES, fr-FR, de-DE, pt-BR**. Show native language names without flags. Native MSFS uses its own readable dark/high-contrast treatment. Those owner-approved choices supersede older open-preference text.

Reuse C1–C8 in the inventory. No parallel recorder, collection engine, evidence store, download queue, organization permission service or deletion controller. No source/QA/calculation changes. New UI state may hold presentation selection, draft text and lifecycle generation, never confirmed recording/science/permission truth.

One primary next action means one visually dominant task action; it does not hide Stop Sharing, Finish, Cancel, pause/hold recovery or explicit privacy/danger review. A fresh authoritative receipt/state determines command outcome. Stale/failed/out-of-order data cannot enable a new unsafe command or relabel an unconfirmed change as saved.

## Screen-level structural wireframes

The following outlines are **static design proposals**. Existing historical browser captures and the required V01–V08 comparison inventory are in the audit. No current screenshots or installed-device acceptance were captured for P01.

### Home

```text
Home                          [Language] [Help]
Connection: MSFS / companion / archive status

Your next step
  Active flight: [Open Current Flight]
  Prepared mission: [Continue Preparation]
  Connected, no mission: [Explore Science Missions]
  Disconnected: [Connection steps]
  (render one matching primary action)

Selected mission / active research / important blocker
Recent real results [Open Results]
[Choose another mission] [Connect Organization]
```

No results means a plain explanation and a next task, not synthetic charts. Offline retained review is offered only when the selected archive is available. Active flight takes precedence over a later prepared plan; show both identities clearly if relevant.

### Missions: Explore, Customize, Prepare

```text
Missions                    [Explore] [Saved Plans] [My Templates]

Experiment: plain-language question
What you can observe / actual source category
Requirements: aircraft/inputs, offline/external data
[Fly Now]                     [Customize]
"Prepares a mission; recording starts separately."

Prepare selected mission
Aircraft + confirmed plan / revision + instruments
Readiness: available / missing / unknown; source dates
[Review Preparation] OR [Open Current Flight to Record]
[Change mission] [Customize route and instruments]
```

The dominant action follows actual readiness/context. Choosing Fly Now may use the existing preparation controller and saved selection but must retain explicit Start Recording. Advanced named sections retain waypoint/airport/manual geometry, patterns, cards/multiple revisions, payload/presets/calibration, units, storage estimate, multi-session/gates and save modes. Do not rename source readiness to permission to fly or guarantee valid science.

### Current Flight

```text
Current Flight: confirmed flight name
Connection: current / stale / unavailable
Flight recording: active/inactive   Science: armed/collecting/paused/held

Next step / current objective        [State-appropriate primary action]
Critical issue → consequence → recovery, when present
Actual retained counts + evidence cutoff/source summary

Map + current route/waypoint        Relevant card / attempt
Compact instrument health           [Record Observation]
[Finish Flight] [Pause/Resume Science when allowed]
[Route Map] [Instruments] [Flight Details & Tools] [Evidence Timeline]
```

Ready/no-flight shows Start Recording through the existing readiness/start controller. After recording, explicit Start/Arm Science remains separate. Finishing recording uses the correct active-flight endpoint and presents the actual resulting status; ending a science session or attempt is not Finish Flight. Detailed telemetry, environment, source/method, calibration and histories remain one named action away. Never turn enabled instruments into a “collecting” indicator.

### Results: three tiers

```text
Results → Recorded Flights [search / status / sort / older pages]
Selected flight: exact identity + actual archive/science state
[Overview] [Explore] [Evidence]

Overview: what was saved; objectives and limitations
Explore: meaningful compatible charts + table/map + selection
Evidence: original UTC/source/unit/QA/identity + attempts + exports
```

| Tier | Default information | Mandatory escape to deeper work |
| --- | --- | --- |
| Overview | Actual flight duration/recorded scope, retained measurements/acquisitions/products with clear denominators, source category/date, qualified objective outcomes; zero/partial/pending/invalid explicit | Open Explore, Original Evidence, Review Recovery, personal/organization outcome context. Keep critical missing/invalid evidence visible without expansion. No invented grade or measured success. |
| Explore | Profile/transect/survey/terrain-appropriate chart, scientific map and accessible numeric table; synchronized **original** selection; compatible comparison or replay as relevant | Source/date/QA/layer controls, additional acquisitions/pages, original sample, methods, exact export. No interpolated missing points, invented timeline join or incompatible subtraction/shared scale. |
| Evidence | Exact original records, typed reference/hash, raw UTC/units/source date, QA/calibration/operating context, session/card/attempt identities, timeline and verified selection | All existing JSON/CSV/ZIP/GeoTIFF, metadata/native-grid tools, paged originals, protected/archive state, explicit Submit Evidence and separate Manage/Delete dialog. Read-only review is not upload/approval. |

Existing mission-workspace coverage/imagery/composites/atmospheric analysis/replay/export and personal family review stay reachable even if not in the first view. After deletion, old grades/maps cannot impersonate deleted science; preserve invalidation and unavailability states.

### Scientific Library

```text
Scientific Library                 [Sources] [Downloads] [Storage]
Sources: full retained inventory; category/provider/date/search
[Find Data] [Import]      (no transfer starts on navigation)
Downloads: selected plan/job/all scope; current work + limitations

Distinguish plan preparation, individual transfer, global preparation and science collection in every Pause/Cancel label. Storage connects to original Windows location/backup/recovery/compaction tools only when the host allows it.

### Organizations, Settings and Help

Organizations opens local assignments, progress, optional live member flights and submission state, with server name/origin and permission scope. No membership shows Connect/Join/Create guidance; personal research remains available. Managers/reviewers get a named portal entry and original role-governed tools. Keep pilot live sharing, submission approval, publication approval and Discord consent separate.

Settings starts with Language and Auto/Light/Dark choice, Units & Display separate; retain map/scientific privacy, Library Storage link, toolbar diagnostics/install, updates and local advanced tools. Help keeps task search, safe offline bundled guides and contextual links, optional external contact and PC feedback collection. Theme/locale change does not modify stored scientific values.
