## P01 — Personal Research first vertical slice

**Implemented:** My Research → Personal Research → Flight-Regime Validation. Save or revise a card, open an existing Mission Planner plan, select it for flight, use normal recording controls, review the completed flight, choose a UTC interval and evaluate its recorded IAS/MSL hold. Saved results reopen offline, including from Mission History. No organization or network dependency. Existing science controls and existing mission grades retain their semantics.

**Contracts:** `PersonalResearchModels`, `FlightRegimeEvaluation`, `PersonalResearchStore` and `PersonalResearchApi` extend existing projects/database/host protections. Plan snapshots retain a null-omitted card identity/revision; attempt records retain its exact definition, flight/time range, raw sequence range/count, source, evidence digest, frozen plan digest and evaluator version. No second recorder, planner, science database or downloader. No new dependency; NuGet lock changes are project-reference version identities only, external pins/hashes unchanged.

**Migration/identity:** additive mission schema 8 → 9; existing verified upgrade backups, rollback, old raw rows and JSON preserved. New development version 0.7.0/prerelease; private v0.7.0 configuration/registry/cookie/toolbar/CommBus namespace remains isolated from published v0.6.0. No private build or installer produced.

**Policy:** `flight-regime-1` uses inclusive IAS/MSL target tolerances and observed contiguous holds at ≤1.5-second sample spacing. Pause/gap/connection events break continuity. Disjoint holds are never summed. Missing/unsupported evidence yields Insufficient Evidence; an adequately observed failed hold yields Fail. Completed supported holds yield Pass, with explicit simulator-only limitations and demo-data disclosure. Selected-interval processing is streamed, cancellable and bounded to 24 hours; inventory/result pages are bounded without an overall ownership cap. Request identities prevent repeated confirmation from duplicating a result.
