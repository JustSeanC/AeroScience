## Separate owner checklist — simple PC steps

The **existing test companion does not need rebuilding**. The new window reuses P08b's native form constructors but has its own schema, checks and sibling `P08c-Results` directory. It never appends IDs to `private_validation_080.TESTS`, modifies the original sealed template or edits old results. It starts no HTTP server, downloads, uploads, recording/science operations or sharing. Append-only writes validate the whole batch, receipt identities, stale edits and measured artifacts first. Failed/Blocked/Not Tested remain distinct.

Copy this block into PowerShell on the test PC. It creates a separate, pinned tools checkout using the existing P08b source folder. It preserves that checkout and the running app; it does not install or rebuild the companion:

```powershell
$ErrorActionPreference = 'Stop'
$PSNativeCommandUseErrorActionPreference = $true
$oldSource = 'C:\Dev\AeroScience-080-Fixed-20261115-095408'
$toolsCommit = 'bfedcbb8b739c8af7774c463d11ff0f9298ae371'
$p08cTools = Join-Path 'C:\Dev' ('AeroScience-P08c-Tools-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
git -C $oldSource fetch origin develop/v0.8.0
git -C $oldSource worktree add --detach $p08cTools $toolsCommit
pwsh -NoProfile -File (Join-Path $p08cTools 'scripts\release\Open-080ScientificChecklist.ps1') `
  -ValidationFolder 'C:\AeroScience-Builds\Validation080-20261115-095408\AeroScience-0.8.0-Validation' `
  -ExpectedSourceCommit '876ecf594956b7a40c7df0d4968dac1ce69ac971' `
  -ExpectedReceiptSha256 '52660521d3a3f04aa62eae266989a6c55467cdeafbec0fd66531fded42bf1447'
```

1. Go down the named list. Choose a result and describe what you actually checked. Leave unavailable work **Blocked** or **Not Tested**. There is no blanket Passed button or test-ID typing.
2. Scientific/resource rows need **Attach evidence** and a complete versioned measured attempt, including its plan/reference/artifacts. Redacted repository summaries or screenshots alone cannot pass. The receipt's actual engineering build stays visible in the record; it does not approve the installed build.
3. For real endurance, start your existing verified companion yourself, then choose **Open longer-flight timer**. It only observes that exact process's CPU/memory. Fly at least 60 real minutes using the existing controls. End the flight and explicitly export its completed **Research Package** yourself; then stop/save the timer and select that ZIP.
4. Add actual legs/sessions/reconnects and observed recording/science states in the checklist. Saving a timer never sets Passed. A pass requires ≥60 minutes of real `Simulator` telemetry overlapping the timer, actual counters, matching package/build/attempt and explicit personal observation. A synthetic replay, idle timer, short run or different build cannot pass.
5. **Save my results** writes only separate P08c records. Keep the measured attempt folders, ZIP exports and receipts intact. GPU and network counters are not inferred from CPU/RAM. No location stream or new shared history is collected.
