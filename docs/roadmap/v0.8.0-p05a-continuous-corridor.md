## Archive audit and historical fidelity

| Retained input | What it supports / limitation |
| --- | --- |
| `telemetry.payload_json` | Full `TelemetryFrame`, including AGL, true heading, GPS ground track, pitch, bank and UTC; map `TrackPoint` is lossy and is not used. Legacy JSON can omit required numeric fields which ordinary deserialization would turn into zero. |
| `collection_inputs` | Exact hashed `TelemetryUpdate` packets associated with collection evidence. Active pose receipts are read from here and checked against the event evidence SHA/time/source identity. Raw JSON field presence is checked **before** pose deserialization. |
| `collection_events` | Original phase transitions, receipt links, session IDs, input UTC and host recorded UTC. Sequence must be contiguous and phase history consistent. The canonical exact-ingress event is reused; arbitrary evidence witnesses for an automatic crossing are not treated as active survey samples. |
| `science_sessions` | Original session ID and append-only effective configurations/revisions/times, including frozen payload/mount/profile/calibration/specification. The configuration actually effective at exposure time is used. |
| Flight events | Connection changes, simulator pause/resume, aircraft changes, telemetry gaps and collection-storage holds. These preserve barriers even where an update was not sampled/retained as a collection input. Free-form messages are not parsed to guess connection state. |
| `science_intents` | Original acquisition identities, exposure/configuration/session/receipt IDs and archived publication state/product SHA. Cancelled or unfinished opportunities remain such; they do not become observations. |

`ScienceCollectionController.Ingest` deliberately retains only flight samples or eligible acquisition opportunities. Thus there is **no high-frequency continuous pose archive**. The reconstruction uses adjacent retained, fresh, valid poses and discloses between-packet modeling. Paused/armed/waiting recordings do not become survey geometry. Modern archived evidence is sufficient for bounded reconstruction; no forward archival change was necessary.

Legacy flights without verified session/pose evidence produce an **Unavailable** diagnostic artifact, never a reconstruction from recording status or today's simulator. Missing position, AGL, heading, ground track or attitude is excluded rather than defaulted to zero. MSL never substitutes for AGL. A payload-null historical effective configuration uses the existing generic fallback, explicitly marked `UsesLegacyDefaultProfile`, with the resolved profile retained separately; the original null configuration remains unchanged.

Completed and interrupted recordings can be processed offline. Only supported adjacent poses inside their original flight/session intervals are swept. Unsupported time from a session boundary to its first pose, after its last pose, or across a transition is not extrapolated. A single supported pose cannot establish a continuous corridor.

## Geometry, timing and uncertainty

Algorithm identity: **`continuous-terrain-corridor-1/sensor-plane-2`**; record contract version **1**. Generic terrain v1 remains **30° × 3°**; versioned `riegl.vq-1560-ii-s.nominal` v1 remains **58° × 16°**. Both are resolved through the existing frozen profile and validation. The RIEGL scanner envelope is an approximation of its scan pattern, not measured laser returns or density.

1. Use true body heading for instrument orientation; GPS ground track is retained/required evidence, not silently substituted for yaw. Geodesic displacement between actual lat/lon endpoints supplies trajectory direction. Use the original AGL feet × **0.3048** conversion, aircraft attitude and frozen mount through `SensorGeometry`.
2. Between sufficiently adjacent supported poses, interpolate position along the WGS84 geodesic, heading along its shortest angular change, and AGL/pitch/bank linearly. Subdivision count is the ceiling of the maximum distance/angle/relative-height step ratio, at least one. Every generated footprint is **modeled**, not a new telemetry packet or acquisition.
3. Re-evaluate the original sensor rays at every step, including intermediate attitude. Existing limits remain authoritative: AGL 1–200,000 ft, rays downward with Z ≥ .15, finite local-plane displacement ≤100 km. Regional/latitude limits below can be stricter. Horizon/unsupported intersections exclude the entire affected pair; they are not bridged with a rectangle.
4. Project footprint corners with the existing geodesic azimuthal-equidistant helper. Union endpoint footprints and triangle lofts between corresponding edges at each step. A whole-leg convex hull would fill the inside of turns and is not used. Union only a bounded regional chunk, preserving holes and overlapping passes.
5. Export RFC 7946 MultiPolygon `[longitude, latitude]` coordinates, correct outer/hole winding and stable ring starts. Reuse the existing 1e-10-degree export snap, topology/area guard and antimeridian split. Bounds for each polygon part stay regional across ±180°. No global mission bounding rectangle or unbounded mission union is constructed.

The model assumes a local horizontal simulator-surface plane. Terrain relief, occlusion and Earth-curvature ray tracing are absent. No simulator/ellipsoid/NAVD88/EGM/MSL datum equivalence is assumed. At 80 km the regional projection's approximate tangential scale term r²/(6R²) is below 0.003%; that is **not** an aircraft-position or sensor accuracy bound. Export snapping is numerical representation precision, not scientific source resolution. Actual motion between packets, positional uncertainty, instrument accuracy and source QA are not established by a dense modeled mesh.

### Continuity and explicit limits

| Parameter | Default | Allowed bound |
| --- | --- | --- |
| Adjacent UTC gap | 5 s | 0.1–10 s |
| Pose age at original host archival time | 6 s | 0.1–6 s; future tolerance fixed at 2 s |
| Geodesic leg length | 5,000 m | 1–10,000 m |
| Absolute latitude, including corners | 85° | configurable up to 85°; polar geometry excluded |
| Interpolation distance / angle / relative AGL step | 50 m / 2° / 5% | 1–100 m / 0.1–5° / 0.5–10% |
| Subdivisions per leg | 128 | 1–256; insufficient fidelity produces a gap |
| Regional radius | 20 km | 0.1–80 km, inside existing 100 km projection guard |
| Legs / interpolation steps per chunk | 64 / 256 | legs 1–128; steps fixed at 256 |
| Local and exported chunk vertices | 20,000 | 16–50,000; over-budget output fails |
| Search windows per chunk / chunks per response | ≤128 / 1 | response limit 1–8 |
| Archive rows / UTF-8 bytes | 500,000 / 256 MiB | up to 2,000,000 / 1 GiB; individual row ≤1 MiB |
| Modeled footprint evaluations / output chunks | 1,000,000 / 20,000 | up to 4,000,000 / 50,000 |
| Published JSON bytes | 64 MiB | 1 KiB–128 MiB |

The existing geographic controller's conservative displacement check is also applied: reject movement beyond `max(300 m, max(endpoint GS) × .514444 × seconds × 3 + 100 m)`. These are reconstruction continuity limits, **not** a maximum safe aircraft speed or an assurance that one-second acquisition timing guarantees coverage.

Split at applied collection/configuration boundaries, changed session/configuration identity, disabled scanner, absent pose fields, non-increasing UTC, stale/future data, paused/disconnected packets, unsupported rays/latitude, excessive temporal/spatial steps, teleports and retained flight-event barriers. Barrier searches use the envelope of observed and host recorded times so slightly future-dated poses cannot hide host connection/pause events. Invalidated input hashes/revisions fail explicitly. No original scientific result is repaired or suppressed to make the model look continuous.

## Durable evidence, invalidation and storage

An artifact of kind **`continuous-terrain-survey`**, format `json`, is a streaming array: header; regional chunk / gap records; archived acquisition references; final summary. Publication is atomic through the existing artifact writer. The header retains actual mission and flight IDs (AeroScience uses the same identity), algorithm/options, original UTC boundaries, limitations, `ModeledGeometry` origin and `GrantsOriginalScienceCredit=false`.

Each chunk retains original session ID, complete effective configuration, resolved geometry profile/version, original input receipt IDs/SHA/UTC/event sequence/origin/host recorded UTC, interpolation count, geodesic distance, precise polygon/holes, local union area, vertex count and geometry SHA. Synthetic test inputs retain `SyntheticFixture` references. Gaps carry reasons/times and original event/receipt identities where available. The summary reports **processing** counts; these are not acquired science, yield, coverage quality or card credit.

The input fingerprint is SHA-256 over length-prefixed UTF-8 fields in a fixed table/key order, algorithm/options/default fallback profile and original flight times/identity. It includes session/configuration history, exact collection event/input rows, archived intent publication references and relevant flight-event barriers. Intents use the existing `(mission_id,state,id)` index order. One read-only SQLite snapshot pins all input passes, then the live input identity is checked again before publication. Volatile processing times/random artifact IDs are outside payload bytes, allowing identical bytes from the same supported archive, options and pinned algorithms/dependencies. Algorithm/contract changes must be versioned.

`Status=Current` means the archive fingerprint and artifact bytes still match; the summary can still be **Unavailable**. It is not source readiness or QA acceptance. Missing/deleted/changed archives, changed publication/configuration references, unsupported algorithms or changed artifact bytes invalidate read/clip/download access. Original acquisition references are historical metadata: inspecting their current bytes/QA still requires the existing original-product reader. No original product numeric values or source files are inputs to P05a geometry.

Future genuine raster and historical point-cloud source contracts contain source ID/SHA, evidence class, acquisition date range, horizontal CRS, vertical datum, QA and provenance. **P05a `Sources` is empty.** No fake date, datum, elevation, return count or source is inserted. Later source-backed artifacts must retain their own immutable dependencies and refer to this geometry artifact/SHA rather than editing it in place.

The existing Library analysis lease blocks source/science maintenance while processing; a maintenance lease blocks reconstruction. Existing capacity checks/reservations account for derived bytes. Cancellation/budget/hash failures clean partial files and managed ledgers and publish no completed product. Permanent collected-science deletion includes derived artifacts/files and prevents recreation from surviving flight telemetry. Clearing flight history retains the separately managed Library according to the original scope, but invalidates orphaned corridor access. No hidden archive backup or source copy is introduced.

## APIs and bounded execution

All endpoints retain existing paired host-session, origin/host and CSRF protections; none accept an organization credential as local owner authorization. No new source permission is granted.

| Endpoint | Behavior |
| --- | --- |
| `POST /api/missions/{id}/terrain-surveys` | Explicit completed/interrupted-flight analysis request; body `{}` selects bounded defaults. Returns original analysis-job contract, kind `terrain-corridor`. |
| Existing `/api/analysis/jobs/{id}` and `/cancel` | Existing queue/history/cancellation contract. |
| Existing mission `/artifacts` and artifact `/metadata` | Original Library inventory/metadata. |
| `GET /api/science/artifacts/{id}/terrain-status` | Current/Invalidated derivation status and reason. |
| `GET /api/science/artifacts/{id}/terrain-chunks?after=0&limit=1` | Up to eight chunks, input fingerprint, precise geometry and source-search windows; `NextAfter` is the last returned chunk index when another exists. |
| Existing `GET /api/science/artifacts/{id}` | Verified streaming JSON download; corridor artifacts additionally require current archive identity. Other artifact behavior unchanged. |

Archive scans and JSON writing/reading stream; processing holds one session/configuration history and one bounded chunk, not an entire flight. A leg temporarily holds at most 2,305 small footprint/loft polygons at the hard 256-step limit. Chunk work is bounded independently of mission length. Cancellation is checked during input scans, footprint generation and between bounded unions. Resource limits stop the operation rather than silently truncate a "complete" product. These structural bounds are not a universal RAM/latency guarantee on every machine; stress/performance and native data acceptance remain necessary.

The original queue is process-local (four waiting jobs, bounded history). Completed artifacts survive restart; an interrupted P05a job is not claimed resumable. Repeating the explicit operation from retained inputs is deterministic. Durable resumable source-processing work belongs to P05b/P05c.
