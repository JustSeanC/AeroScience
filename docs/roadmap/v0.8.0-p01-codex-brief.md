## Goal

Produce a **complete evidence-based audit and migration map** for a radically simpler AeroScience dashboard and MSFS 2024 toolbar, while protecting every working scientific, research, organization, storage, permission and historical capability. The novice journey is Explore Mission -> Prepare -> Explicit Start Recording -> Explicit Start/Arm Science -> Fly -> Finish -> Understand Actual Results. Advanced functionality stays accessible through progressive disclosure.

This is P01, not a code rewrite. Avoid speculative implementation and avoid deleting or rebranding controls before their existing handlers and data contracts are inventoried.

## Required v0.8 conventions

Main dashboard: Home, Missions, Current Flight, Results, Organizations when relevant; Scientific Library, Settings and Help as utilities. Short, contextual labels. One primary next action per operational screen, but never remove explicit consent, readiness or safe separation of recording vs science. The toolbar is not a clone of the dashboard. Primary locales proposed en-US/es-ES/fr-FR/de-DE/pt-BR with a shared catalog contract and native runtime adapters. No flag-language mapping, no loss of source/UTC/unit provenance.
