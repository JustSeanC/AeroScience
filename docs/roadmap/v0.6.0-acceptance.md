# v0.6.0 acceptance contracts

Evidence classes: **A** unit/synthetic; **B** real-process integration; **C** genuine official original plus
independent numerical/geographic comparison; **D** owner-installed Windows + official SDK/MSFS,
physical iPad Safari and Quest 3. Record exact source SHA, command, counts/skips and actual evidence.
A/B passing never substitutes for C/D. No criterion is passed by this specification alone.

| ID | Required acceptance |
|---|---|
| BASE-06 | Exact baseline/branch/upstream, clean incremental commits, protected heads/tags/releases unchanged; all baseline regressions retained. |
| AVI-CONTRACT | Versioned identities, UTC/Unknown semantics, official URL/redirect allow-list, bounded geometries/queries, no source/scientific-budget crossover. Unsupported versions fail closed. |
| AVI-STORE | Independent identity/schema; additive backup/integrity/rollback; one writer, missing drive, permission failure, offline reads, atomic interruption/restart; no silent originals cleanup. |
| AVI-JOBS | Real approved intent/hash, known/unknown budgets, bytes/reservations, pause/resume/retry/cancel/idempotency/process-kill recovery; changed asset/ranges/ETag, 429/503, consent/metered/flight priority and disk exhaustion. |

| MAP-02 | Exactly one basemap and independent Mission/Science/FAA/TFR groups; preserve view/draft/filters; legend/edition/as-of/opacity, keyboard/screen-reader list/touch and narrow iPad layout. X/Escape/focus recovery; native toolbar stays lightweight. |
