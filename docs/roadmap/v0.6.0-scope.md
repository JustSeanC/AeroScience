# v0.6.0 scope — Aviation Mapping & Scientific Data Expansion

Status: development on `develop/v0.6.0`; not released or owner accepted. Base:
`2419efa22a4205fdbcc0dbe2b8f06fa07a6586b2` (current main and develop/v0.5.0).
The [tracker](v0.6.0-development-tracker.md) distinguishes implementation from evidence.

| Group | Approved behavior | Integrity boundary |
|---|---|---|
| MAP-01 | Additional authorized compatible Esri terrain/topographic/geographic raster basemaps | Existing four identities, consent, DPAPI key and offline fallback survive; vector-only styles are not raster tiles. |
| MAP-02 | One basemap; independent Mission, Science, FAA and TFR overlays on dashboard/paired browser | Preserve drafts, view, science filters, session state; accessible list alternatives and shared X/Escape/focus handling. |
| FAA-01–04 | VFR sectional, TAC, helicopter and IFR low/high GeoTIFF charts | Actual editions, original files, CRS and main-body neatline; no georeferenced PDF substitutes or projected margins/insets. |
| FAA-05–07 | FAA airports/heliports/runways, Class B/C/D/E, supported SUA, NAVAIDs/fixes | Official cycle/datum/altitudes/schedules; unknown facts stay unknown. OurAirports remains distinct/global. |
| FAA-08 | Catalog, explicit approved downloads, managed originals, local rendering, updates/expiration and offline reuse | Separate aviation storage/accounting, no silent original deletion, safe bounded extraction and recovery. |
| FAA-09 | Official TFR notices; validated boundaries when available; time/altitude-aware mission screening | Never guess boundaries/times or claim complete coverage from a list. No warning blocks recording or collection. |
| SCI-01–02 | Native EMIT original NetCDF-4 reflectance, companions/QA/uncertainty/geolocation, geographic views, spectra, exports/offline reuse | Real values, wavelengths and GLT; V2 reflectance/uncertainty may pair with V3 mask. Original versions and hashes remain separate. |

Shared requirements: local-first; no hosted backend or mandatory account; bounded viewport/pagination,
request/transfer/storage budgets, cancellation and restart safety; one-second recorder priority;
paired-device authentication/CSRF and credential redaction; user-selected missing disks fail closed.
Scientific and aviation originals must remain protected and distinct. Universal/Realistic, all compatible
aircraft, immutable snapshots, multi-session collection, grading, exports and ENVI compatibility survive.
Simulator integration stays read-only. Existing SDK/runtime/installer gates remain mandatory.

Excluded: Navigraph/packages/accounts, third operating mode, real-world certification, invented
scientific observations/TFR polygons, simulator/autopilot control, new camera instrument, public
installer/release/tag/PR/merge. Private builds require the existing isolated profile protections.

Scientific, Windows/MSFS, iPad Safari and Quest acceptance are independent gates, not CI conclusions.
