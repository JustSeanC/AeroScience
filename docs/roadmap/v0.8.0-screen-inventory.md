**Audit date:** 2026-11-10. **Source:** `develop/v0.8.0` based on the current v0.7.0 implementation; static GitHub code/document review only. **Status:** P01 architecture/navigation inventory; runtime behavior requires separate browser and real Windows/MSFS checks. ## Routing reality and alias invariants

`src/AeroScience.Engine/wwwroot/app.js` keeps this allowed-page set: `control`, `operations`, `planner`, `history`, `instruments`, `settings`, `science-workspace`, `library`, `help`, `downloads`, `my-research`, `library-storage`. It also recognizes or redirects `#results` -> history; `#science` -> instruments; `#workspace/<subpage>` -> science-workspace; `#library/storage` -> library-storage; `#settings/<category>`; `#settings/support` -> help; `#workspace/timeline?missions=...` -> `#operations?flight=...`. Unknown hashes fall back to `#my-research` in v0.7. **Do not redirect legacy bookmarks to an unrelated v0.8 Home without an intentional compatibility map.** Preserved query `missions`, `instrument`, `researchPlan`, `flight`, `connectOrganization`, `permission`, and future unknown compatible parameters must be audited before route changes.

`task-workspaces.js` currently groups `control/operations/instruments`, `history/science-workspace`, and `library/downloads/library-storage` by **reparenting live DOM**; it is not three independent replacement controllers. `workstation-shell.js` implements responsive navigation, keyboard focus restoration and disclosure of flight details/tools. `settings-navigation.js` owns per-category settings navigation.

## Lifecycle / risk state matrix (mandatory preservation)

- **First-run / no engine / remote access:** show pairing/launch action and exact failure, never fake Connected or enable commands. `app.js` uses session/CSRF and bridge identity; toolbar requires a matching companion reply.
- **No aircraft / paused MSFS / stale telemetry:** show explicit reason, fail closed for unsupported actions; no old flight silently reused.
- **Mission plan prepared but not recording:** distinguish ready state, plan snapshot, source readiness and optional online download permission; keep both Fly Now and Customize.
- **Recording without science:** flight samples are not scientific observations; prominent Start Science or actual Armed trigger. Science paused may coexist with continuous flight recording.
- **Collecting but invalid source/geometry/storage:** preserve actual QA and saved/rejected/missed counters and critical failures. No invented terrain intersection or coverage.
- **Mission ends / older archived review:** preserve frozen plan/card revision, original record IDs, science deletion status, results/provisional pending, separate review and organizational approval.
- **Data unavailable or deleted:** don't reconstruct science originals from telemetry or promise cached copies. Desktop deletion preview/execute and active-use blockers remain authoritative.
- **External data prep:** offline source reuse/cancel progress/queue permissions stay intact; navigation cannot authorize new downloads.
- **Organization no membership / expired authorization:** no shared data; reauthorize explicitly. Live monitoring is separate opt-in; drafts and offline queues never count as granted upload.
- **Localization:** original UTC/source date/hash/quantity never mutate; locale changes only presentation; all 5 first-wave languages require reviewed destructive and consent copy.

This inventory was assembled from repository files, not an instrumented browser or SDK build. It maps the major named routes/views and principal control groups; it is **not** a guarantee that every dynamically generated `button`, dialog, CSS state, keyboard behavior, or endpoint has been enumerated.
