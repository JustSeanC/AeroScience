## Presentation and authority legend

**Prominent** means present in the main task flow. **Contextual** means directly available when its flight, card, selection or role applies. **Advanced** means a named, keyboard-accessible disclosure or secondary screen, never a hidden global expert mode. **Utility** means a consistently discoverable Library, Settings, Help or separate organization/Windows tool. Nothing is proposed for deletion.

Owner-approved baseline: dashboard **Auto** theme with optional override; **guided** first-time experience; **balanced** density; **en-US, es-ES, fr-FR, de-DE, pt-BR**. Native contrast/readability takes precedence over desktop theme. Implementation and fluent-language/native-font acceptance remain outstanding.

Authority codes make the matrices readable. Client rendering is a read projection unless a listed existing action explicitly invokes a controller.

## Required status coverage

| Situation | Required presentation and retained controls |
| --- | --- |
| First run, pairing pending, engine starting, no aircraft, no saved plan/results | Explain next recoverable step; saved local work and Help remain reachable. Do not render synthetic example data as real results. |
| Offline external network vs disconnected MSFS vs unavailable selected drive | Separate source retrieval, simulator telemetry and storage. Offline local review works only when its archive is available; missing drive is not an empty new archive. |
| Simulator paused/invalid telemetry; science armed/paused/held; recording ended | Independent recording/science/card indicators. Do not label the recording Paused because telemetry or science pauses; no new recording-pause endpoint exists. |
| Fresh collecting but zero observed data; rejected/missing/skipped/unassessed; storage fault | Actual acquisition/measurement/validity counts with their denominators and evidence cutoff; zeros stay zeros, unknown stays unknown. Critical issue + consequence + next action outside collapsed detail. |
| Pending command, failed receipt, stale/reordered response, engine/flight/session changed | Disable unsafe command and explain synchronization/retry; keep original IDs/request semantics. A reply parsing fault and a display fault are different. |
| Historical source, modeled output, pilot note, unavailable input, synthetic fixture | Visible source category and acquisition date/UTC/unit detail; translation cannot alter evidential meaning. |
| No organization, no membership/scope, revoked permission, queued submission, withdrawn live share | Personal work remains; recipient/permission/consent states explicit. Queued, received, reviewed and approved are separate. |
| Permanent delete pending/blocked/partially cleaned | Scope + exact irreversible confirmation + preservation/blocker text. Do not claim rollback, backup or complete deletion when managed/database cleanup remains pending. |

Every row is a preservation obligation, not permission to operate on an owner archive. P01 changes only its three roadmap documents; runtime behavior, existing data, release assets and other branches remain untouched.
