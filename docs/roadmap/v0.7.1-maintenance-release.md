## P01: source metadata

Confirmed failure: v0.7.0 writes retained STAC envelopes with `scene` and canonical band IDs, then gap preparation calls the raw-item parser expecting `id` and provider keys. New regression cases reproduced `KeyNotFoundException` for Sentinel, Landsat and Copernicus. Malformed assets could also terminate discovery before a later valid scene.

The parser accepts the original retained envelope without rewriting it or changing its revision hash, validates required field types and original numeric scaling/QA, and skips incompatible automatic-discovery candidates within the existing bounded search. Catalog display fields such as unknown file sizes, projection hints and update times are optional; their absence does not alter numeric measurements. Unknown cloud quality is not presumed clear. Errors identify a fixed provider host and field, without echoing returned values, private coordinates or signed URLs. Exact selected-scene revision refusal remains in force.

A metadata-only current Earth Search check returned the expected Sentinel-2 COG asset names, scale `0.0001`, offset `-0.1` and native SCL metadata. No tester coordinates, raster download or genuine airborne observation was used. The tester's actual metadata response has not been supplied; this reproduces a relevant mechanism, not proof of that tester's exact cause.

Validation: initial ten new regression cases failed against the baseline. The first affected selection passed 46 cases and exposed one consent exception regression (overbroad metadata catch); the catch was narrowed and original assertion retained. Corrected targeted selection: **50 passed, zero failed/skipped** (automatic source preparation, catalog and verified source reuse). Original logs and TRX files are preserved in the isolated work area.

## P02: explicit retry

Continue/resume only requeue interrupted work; failed/unavailable selected rows use the explicit `retry` command. Retry preserves user/post-flight pauses and does not alter consent, budgets, provider limits or verified ready sources. Failure states survive restart; ready sources are reverified through existing local reuse. Retrying a selected subset no longer clears other scope rows, and allowance-wait jobs retain their original queued ticket. Scheduling prevents two executions of one key while cancellation cleanup completes. No automatic failure retry loop was added.

Affected selection: **58 passed, zero failed/skipped**, including metadata/network/rejected/rate-limit failures, restart, idempotent paused retry, post-flight hold, offline consent and verified multi-source reuse/deletion dependencies.

## P04: zoom-independent acquisition visibility

A deterministic held-native-request test reproduced an existing race: zooming while the first scope loaded discarded `moveend`, leaving a zoom-17 overview after zooming out. Initial loading now compares the final viewport and refreshes once when it changed. The overview records the scale of its actual query, rather than assuming the current map still matches that query.

The existing bounded overview bins also draw unfilled dashed acquisition extents beside their location markers. They explicitly describe modeled acquisition locations/extents, include unknown/missing areas, and remain separate from flight tracks and true valid native-cell support. No footprint is painted as a continuous scientific surface. Native terrain canvases, values, masks, dates and selection remain intact. No new DEM, LiDAR, interpolation, point-cloud or 3D system was added.

Validation: **27 affected .NET workspace/profile cases passed**. The three existing terrain browser cases passed with unchanged pixel, native-density, canonical-unit and original-hash assertions. The new deterministic initial-load/zoom case failed against the old lifecycle, then passed at **zooms 5, 9 and 15**, checking projected visible locations, mounted unfilled extents, bounded layer count and unchanged product hash. Static-asset setup errors, canvas/SVG test assumptions and local startup timeouts remain preserved in the work-area logs; no existing assertion or deadline was weakened. Final clean-source CI remains the integration gate.
