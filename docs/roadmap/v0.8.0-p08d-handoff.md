## Required owner work and beta policy

The cloud checks do **not** establish a genuine SDK package, authorized shipped runtime, signed prerequisite, sealed installer, exact-installer install/uninstall, actual MSFS operation or owner acceptance. Those remain Blocked/Not Tested until the owner's Windows candidate build/checklist runs. Signing/reputation status must be recorded truthfully. The builder defaults to valid signatures; the guide's explicit `-AllowUnsignedBeta` records a deliberately unsigned beta choice, never an invalid certificate or unsigned Microsoft prerequisite. Distribution still requires owner review/approval.

Use the pinned source and Full CI run from this handoff in [the owner instructions](v0.8.0-p08d-beta-acceptance.md). Build into a new `Beta080-*` folder, preserve its installer/receipt/checksum/payload/logs, install it yourself in an isolated Windows test environment, and open the separate eight-row checklist. **Verify installed files**, record meaningful personal observations, export observed acceptance and compute readiness. Nothing inherits earlier private-build passes. Do not send the earlier private ZIP as Beta 1.

Long flights, multiple sessions/legs, large terrain/LiDAR inventories, broad aircraft/hardware/providers/regions, prolonged interruptions, wider installed accessibility and qualified fluent-language review are **Deferred to beta testing**. They need not pass before packaging/distribution of an honestly labeled beta. A known critical corruption/privacy/security/install defect still blocks distribution. Indexed COPC and unvalidated CRS/vertical transforms remain unsupported.

P08c's exact measurements/datasets and limitations remain as recorded in [its handoff](v0.8.0-p08c-handoff.md), accepted tools `bfedcbb8b739c8af7774c463d11ff0f9298ae371` and [CI 43746786812](https://github.com/JustSeanC/AeroScience/actions/runs/43746786812).
