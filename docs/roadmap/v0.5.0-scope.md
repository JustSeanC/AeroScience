## INST-01 — Advanced Instrument Calibration

Extend the current instrument catalog and versioned reference profiles:

1. Describe applicable calibration parameters, units, status, references and sensitivity
   limits for each supported atmospheric/remote instrument. Unsupported or unverified
   properties remain unknown, not calibrated by default.
2. Freeze versioned effective instrument settings, reference specifications and optional
   user-supplied calibration definitions/provenance. Edits create new revisions; old
   missions retain their effective versions and original values.
3. Validate user data, applicability, units and documented operating envelopes. User
   statements are not manufacturer certification. Parameter changes must identify a
   custom configuration and distinguish geometry adjustments from radiometric processing.
4. Separate simulator-reported measurements, optional derived/calibrated values, modeled
   geometry and independently observed external datasets. User calibration must not rewrite
   source bands/QA or claim that Landsat/Sentinel has acquired the referenced camera's
   radiometry, resolution or accuracy.
5. Never invent certificates, accuracy, drift, random faults, wavelengths or missing
   parameters. Legacy missions remain readable without retroactive calibration claims.

## INST-02 — Hybrid Realistic Mode & Operating Constraints

Keep `ScienceMode.Realistic`; Hybrid describes its assessment policy, not a third mode.

1. Assess applicable AGL/documented ranges, groundspeed versus sample spacing, pitch/bank,
   mount orientation and footprint validity, actual acquisition cadence and intended overlap,
   documented environmental/temperature limits, source availability and measurement capability.
2. Return per-rule reasons/evidence and distinguish supported, caution, invalid-derived,
   unavailable and not-assessed outcomes. Unknown payload temperature is not a measured
   internal temperature merely because ambient simulator temperature exists.
3. Operating advisories do not arbitrarily stop collection. Preserve valid raw readings
   and source values. If a derived geometry/value is scientifically invalid, withhold or
   explicitly invalidate that derivation; do not present it as valid data or erase the raw input.
4. Operating compliance is a separate assessment from source QA, observational quality,
   data availability and pilot grading. Universal retains flexible collection with honest
   scientific-validity guards, but no Realistic-only operating penalties.

## DATA-01 — Geographic Scientific Data Library

Implement the complete [existing DATA-01 workflow](v0.5.0-backlog.md#data-01--scientific-data-library-browse-and-download-by-geographic-area):

- Full-page Library geographic browsing of verified retained coverage and actual provider
  availability. Distinguish local, catalog, selected, queued/downloading/failed, unavailable
  and not-searched areas; a scene outline never guarantees QA-valid pixels.
- Select one bounded cell, multiple cells, viewport, rectangle, polygon or supported
  authoritative regional boundary, with accessible numeric/place-selection alternatives.
  Cells are preparation work units, not native satellite pixels.
- Select source, product/measurement, exact scene/date, required bands, resolution and
  quality policy. Keep Landsat, Sentinel, bare-earth 3DEP and Copernicus DSM distinct.
- Preview exact work, known scenes, reusable versus fetched content, geographic limits,
  unknown estimates, network/storage allowances, terms and large-job implications before
  explicit approval. Changing material scope invalidates that approval.
- Queue bounded work with pause/resume/retry/cancel and durable restart behavior. Reuse
  current providers, efficient numeric/range reads, source validation, storage reservations,
  hashing, provenance, bandwidth controls and live-flight prioritization.
- Retain genuine results for offline reuse without requiring a current mission. Preserve
  manual import. Source-library acquisition and mission scientific observation are different
  operations; neither exporting nor downloading is an aircraft observation.
- Larger/state selections require assessment, scene/date limits, subdivision and capped
  work, with smaller/chunked alternatives. No unrestricted country download, all-history
  satellite request, fabricated ETA or silent expansion of budgets/cleanup permissions.

## SCI-01 — Mission Science Scoring & Grading

Evaluate research planning/execution for Realistic missions, not scientific accuracy.
Initial rubric category weights are Mission Design **20%**, Sensor Operating Compliance
**30%**, Flight Plan Execution **25%**, Acquisition Discipline **25%**.

- Version mission-specific rubrics, applicability, effective settings and evidence inputs.
  Geographic survey criteria must not be imposed on atmospheric profiles or general flights.
- Provide provisional live scores, final A–F grades when evidence is sufficient, per-instrument
  Good Data percentages, collection completeness, scientifically valid geographic coverage,
  operating compliance, explanations, missing-evidence status and corrective recommendations.
- Preserve one overall flight/mission grade with session-level performance and independently
  reportable science metrics. End Data closes a session, not the overall grading evidence.
- Keep source QA/yield, acquisition completeness and pilot-performance grading distinguishable.
  Give every percentage its numerator, denominator, scope and method; do not infer complete
  coverage from route adherence or a map rectangle.
- Handle unsupported criteria, unavailable evidence, provider failures and legitimate
  transit/pauses fairly. Freezing expected obligations must prevent selective collection,
  deleting hard segments, selectively ending/restarting sessions or disabling instruments
  from artificially improving a grade. Roll up frozen obligation evidence, not averages of
  session grades or only the best sessions; session boundaries cannot reset denominators.
- Reproduce results offline from archived settings/events/inputs and frozen grading rules.
  No retrospective change to originals or overwrite of previous grade revisions. Legacy
  missions without sufficient evidence show Not graded/Insufficient evidence.
- Leaderboards, achievements, social ranking and competition are out of scope.

## SCI-02 — Preflight Scientific Mission Readiness

Extend existing Planner preparation/sensor/storage views with an integrated assessment of:

- Objective/template, route/survey design and intended scientific obligations.
- Instrument/calibration configuration and documented envelopes; planned AGL versus MSL,
  groundspeed, spacing/overlap, geometry and achievable sampling cadence.
- Scientific source availability, dates/QA limitations, storage and acquisition budgets.
- Collection/session automation references, optional explicit End triggers, next-session
  Start reachability/order, survey boundaries, manual-rearm requirements and
  whether the planned evidence supports meaningful grading.

Use Ready, Caution, Unavailable and Not Yet Assessed per check, with actions/reasons and
assessment time/input revision. Ready is not a guarantee of future source pixels, scientific
accuracy or flight outcomes. Save incomplete drafts freely; noncritical concerns remain
advisories. Existing recording/storage/security hard protections remain enforced.

## SCI-03 — Automated Science Collection

Extend current science pause/resume with multiple identifiable collection sessions inside
one continuous flight recording:

- **Start Data** opens a new session when none is open; **Pause Data / Resume Data** retain
  the current session ID; **End Data** means **End Current Science Session**. Closing a
  session never ends the flight or prevents a later explicit Start from opening another.
- Start/Pause/Resume may use configured route points/gates and applicable area-entry rules;
  optional boundary automation pauses outside and resumes the same open session on re-entry.
  Automatic **End** is optional and requires an explicitly configured route point/crossing
  gate. Never infer End from the last waypoint, route completion or survey-polygon exit.
- After an automatic End, a later distinct configured automatic Start can create another
  session with fresh valid evidence. After a **manual End**, suspend automatic starts until
  explicit pilot rearm; the pilot can manually Start New Science Session meanwhile. Manual
  control does not silently rearm automation. Never reopen a closed session through Resume.
- Manual overrides and scoped pause holds remain authoritative. Flight can start at departure
  with science Armed, collect/pause/resume in several research areas, close each session and
  continue transit/return recording. No open session means no scientific acquisition.
- Each session has a stable ID, mission linkage, timestamps/end reason, effective instrument
  configuration snapshots/timeline, provenance, attributable collection events, source/product
  references and independently reportable metrics. Preserve prior sessions when starting another.
- Distinguish **End Current Science Session**, optional **Finish Science for This Flight**
  and **End Flight** in contracts and UI. A flight-wide Finish action is deferred, not an
  alias for End Data; End Flight finishes recording and closes any open session explicitly.
- Fire each configured occurrence once. Handle duplicate telemetry/repeated crossings,
  stale/gapped/out-of-order positions, slew/jumps, reconnects and interruption conservatively.
  Occurrence receipts remain flight-wide across sessions; bind commands/work to the intended
  session so an old End or late result cannot affect a newer session. Every transition,
  override and suppression must have durable attributable evidence.
- Evaluate triggers in the backend mission engine even when no browser/map/toolbar is open.
  Preserve manual pause/resume compatibility and historical archives. Keep planned transit
  and legitimate pauses distinct from omitted required collection for grading. Frozen
  mission obligations survive early Ends, new sessions and plan edits without selective grading.
