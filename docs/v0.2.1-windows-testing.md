## Repairing an older Windows checkout's bundled-asset hashes

If the build stops with `Bundled web asset missing or changed: vendor/chart.js/LICENSE.txt`, Windows Git may have converted LF to CRLF while checking out the hash-pinned files. `.gitattributes` now preserves the exact original bytes in the vendor and geography trees, including upstream files that intentionally use CRLF. Integrity checks and the manifest's expected hashes remain unchanged.

For an existing affected checkout, run this in PowerShell from the repository. These commands restore only the committed third-party map/chart/license/geography assets and their source manifest; preserve any intentional edits to those files first. Mission data, settings, SDK files and release records are outside these paths.

```powershell
Set-Location 'C:\Dev\AeroScience-release'
Remove-Item -LiteralPath '.\src\AeroScience.Engine\wwwroot\assets-manifest.json'
git -c core.autocrlf=false restore --source=HEAD --staged --worktree -- src/AeroScience.Engine/wwwroot/vendor src/AeroScience.Engine/wwwroot/geography src/AeroScience.Engine/wwwroot/assets-manifest.json
git pull --ff-only origin main
python .\scripts\build\verify_web_assets.py
git status --short
```

Expected: `Verified 26 bundled geography/library/license files...`, then no Git changes. The restore resets both the staging area and working files for only these bundled assets and their manifest, including staged line-ending changes left by the earlier repair instructions. Temporarily removing the tracked manifest forces Git to recreate it, even if Git considers its old CRLF form clean after normalization. The next command restores the committed file; no manifest hashes are regenerated. `core.autocrlf=false` applies to that command only; it does not change your Git settings. The new `-text` attributes preserve original LF and CRLF bytes, while `assets-manifest.json` uses LF. This also prevents a false dirty-checkout failure after upgrading the attributes. Omit the earlier `git add --renormalize` step, which can stage already converted files. Re-run the original build command after verification succeeds. Fresh checkouts pick up the attributes automatically. Do not change expected hashes or bypass verification to work around this failure.

- Close MSFS; update via the common progress window. Copy/verify percentages must use actual file counts; backup/activation stages may be indeterminate. Confirm final package verification, restart instructions, outside-Community backup and unrelated add-ons preserved. Use a disposable Community folder to exercise locked files/disconnected media and rollback. Test first-run, startup and Settings entry points.

- Record actual atmospheric science. Compare supported values against the simulator. Change C/F/K, pressure, wind, density and altitude/distance display units; match desktop/iPad/toolbar/history/charts. Original JSON/default CSV values must retain canonical units. Inspect Mach and the existing read-only guidance; no aircraft control may change.
- Pause science from a browser; observe the toolbar and a second browser. Flight telemetry must keep recording, science counts/datasets stay stable and no samples are invented. - Use offline geography with internet disabled: known airport/city/coordinates, valid 0,0, route fit, wheel/touch zoom, aircraft centering and manual edits. Draw/edit/delete survey polygons. - Save/rename/edit/duplicate/apply/delete instrument presets in Science and apply in Planner. Route/objective must remain unchanged. Confirm recorded snapshots stay unchanged after preset edits/deletion and unknown instruments are warned, not enabled.
- Fly a plan, end it and review ordered waypoint tolerance, closest passes versus reached points, missing track gaps, deviation samples, altitude error and polygon path traversal. - Inspect Science cards, real-data charts/axes/tooltips/range/expanded view/points/PNG/display CSV and canonical full exports. Check 125%/150% zoom, desktop widths and physical iPad Safari touch. No full-page horizontal scroll or clipped primary controls.
- On disposable stores, clear science and flight independently, both with **Permanently delete without creating a new backup** and **Create a recovery backup, then delete**. No-backup must open no folder picker. Preview the exact data location, counts, preserved content and phrase. Backup must be outside the deletion/installation scope. Test cancel/wrong phrase/recording guards, plans optional, presets retained and unrelated files retained. SQLite may retain allocated file size after row deletion; no compaction occurs silently.
- Retest offline startup/history/export with MSFS closed, separate-drive migration/unavailability, upgrade and uninstall/reinstall with toolbar Keep/Remove choices. Test Quest 3 interaction and sustained FPS/frame time/CPU/memory separately; browser simulations cannot establish VR performance.
