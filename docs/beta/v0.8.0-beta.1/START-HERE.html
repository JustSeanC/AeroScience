AeroScience v0.8.0 Beta 1

This is a testing version, not a stable-release certification. Your usual AeroScience installation and data stay separate. Pick a few testing cards that interest you; you do not need to test everything.

Install · First science flight · Results · Report a problem · Remove or return

Install and connect

  1. Download AeroScience-Setup-v0.8.0-beta.1.exe from the owner-approved beta location. Check that it says Beta 1. Keep the supplied checksum. If Windows reports an unexpected publisher/signature or you are unsure about the file, stop and ask the owner; do not disable security software.
  2. Close MSFS and any other AeroScience companion. Run the installer and choose an empty beta application folder. If the signed Microsoft Visual C++ prerequisite needs installation, approve its normal Windows prompt. No SDK, compiler, Python, Node.js or Git is needed by testers.
  3. Open AeroScience 0.8.0 Beta 1. It uses its own beta data folder and will not adopt your usual research automatically.
  4. With MSFS still closed, open Settings and install the matching Beta 1 toolbar into your existing MSFS 2024 Community folder using the folder picker. Do not copy DLLs or edit registry settings.
  5. Start MSFS 2024 and load a flight. Open the AeroScience Beta 1 toolbar. Check that the companion says Connected. A disconnected/stale warning means current flight information is unavailable.

Try a first science flight

  1. Open Missions and choose an experiment. Read the actual aircraft, instrument and source requirements. Fly Now prepares/selects the mission; it does not start recording or science.
  2. Prepare the requested scientific sources. Downloads require your explicit permission and limits. You can decline, work offline with retained sources, or choose another task. Missing data must stay missing.
  3. Choose Start Recording. Confirm recording is active. This alone does not mean science is running.
  4. Use the separate science action: Start Science or Arm Automatic Collection, as offered. Armed/waiting is different from collecting. Try pausing science while flight recording continues, then resume it.
  5. End science and the flight using their existing controls. Keep observations and card actions explicit; focusing a card does not activate or complete it.

Inspect actual Results

Use Overview, Explore and Evidence to inspect saved observations and provenance. A modeled scanner corridor is predicted geometry. DEM/DSM surfaces and historical LiDAR are external historical data, not measurements made by the MSFS aircraft. DSM can include vegetation/buildings. Unknown source dates, height references and coverage remain unknown; source date is not simulated flight date.

Try the original-value table or 2D view if 3D is unavailable. A displayed subset does not change original counts. Never treat a track or modeled footprint as proof of measured scientific coverage. Indexed COPC and unsupported coordinate/vertical transformations remain unsupported.

Organizations are optional. Connecting, claiming an assignment or recording does not authorize live sharing or evidence uploads. Review the exact recipient/content before explicitly approving submission. Local card evaluation is different from organization scientific approval.

Report a problem

In the companion, choose Collect Feedback. Select a testing area/card and describe what you expected, what happened, and steps to reproduce. Add aircraft/MSFS/hardware details if relevant. A screenshot is optional. Review all fields and the screenshot, then save the local ZIP. Open and review it before manually sharing through the owner's agreed channel or GitHub Issues.

No report, scientific file, log bundle, organization record or location history is uploaded automatically. Do not share pairing codes, credentials, private messages or original scientific files. For possible corruption, data loss, unauthorized sharing or installer damage: stop the beta, preserve files/logs, and report it as critical. Do not delete your only copy to investigate.

The four non-English languages are candidate translations awaiting fluent review. Tell us the chosen language, screen and confusing phrase; critical missing resources use English fallback. New beta feedback controls are currently English. This does not imply complete human review.

Uninstall or return safely

To remove the beta toolbar, close MSFS and use the beta companion's Settings before uninstalling. Then close the beta and uninstall AeroScience 0.8.0 Beta 1 in Windows Installed Apps. Beta research/settings remain in %LOCALAPPDATA%\AeroScience-Beta-v0.8.0; other AeroScience installations are retained. Do not erase that folder unless you separately intend to delete your beta data.

Close the beta before reopening your usual AeroScience companion. Beta 1 refuses to overwrite existing installations. In-place upgrades/downgrades are not certified; later beta instructions will explain supported upgrades. See known limitations, optional testing cards and release notes.
