# AeroScience v0.8.0 Beta 1 — Known limitations

Beta engineering is not stable-release or provider-wide certification. Exact-candidate basic Windows/MSFS/installer acceptance is required before distribution; cloud compilation alone cannot supply it. The owner distributes only after reviewing those results. An explicitly permitted unsigned beta may show Windows publisher/reputation warnings; signing status and hashes must be supplied honestly. Do not disable security protections.

- Longer flights, large mosaics/clouds, multi-leg sessions, different aircraft/hardware/GPUs/regions/providers and prolonged interruptions are intended beta testing activities, not pre-beta certification requirements.
- es-ES, fr-FR, de-DE and pt-BR are candidates. Qualified fluent review is pending; critical fallback and all five language choices remain. New beta feedback controls are currently English. Wider native accessibility/screen-reader evaluation remains a testing activity.
- Historical LiDAR is genuine historical source data, not live airborne LiDAR. Root/coarse EPT nodes and viewer subsets are not full-density coverage. Indexed COPC, unsupported CRS/vertical transformations and inferred height above ground remain unsupported.
- DEM versus DSM, source date versus flight date, source datum versus simulator MSL, and modeled corridor versus measured coverage stay distinct. Unknown/missing data remains unknown. Coverage/provider outages can prevent an experiment; retry does not create valid data.
- Beta data is confined to its own local beta profile. Import explicitly selected source originals through the existing importer; do not point it at production research. Keep adequate space for retained originals and disposable testing. Original data is not migrated automatically.
- Only one companion runs at a time. Beta toolbar/channel/package differ from production/private validation. Close MSFS to install/remove the toolbar. The uninstaller retains Community packages and beta data; remove the beta toolbar explicitly through beta Settings first if desired.
- Beta 1 supports fresh application installation. It refuses to overwrite an existing beta/tester app. Later in-place upgrade/downgrade compatibility is not claimed. Explicitly uninstall the beta app, retain its data, and follow the next beta's instructions.
- Protected NASA originals, provider-family accuracy, scientific conclusions, hardware frame rate and all-format interoperability are not inferred from P08c's bounded independent comparisons.

Report critical corruption, data-loss, privacy/authorization or installation defects immediately and stop affected testing. Optional QA cards never grant scientific mission credit or organization approval.
