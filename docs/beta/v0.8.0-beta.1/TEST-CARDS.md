# Optional Beta 1 QA cards

The owner can assign one or two cards per person. These are **beta QA**, separate from scientific test cards, mission completion, grades and organization research contributions. Do not create research credit for QA results. Use the in-app Collect Feedback report with the card label and actual build/version. Untested work stays untested; a missing source or unsupported configuration is useful feedback.

| Card | Activity | Useful observations |
| --- | --- | --- |
| QA-FLIGHT | A normal flight, then optionally 60+ minutes, more sessions/legs or another aircraft | Actual duration; recording versus armed/collecting/paused science; instruments; intervals; reconnects; saved results |
| QA-SOURCES | One explicitly approved genuine DEM/DSM, historical LiDAR, satellite or atmospheric source | Actual provider/product/date or unknown; prerequisites; consent/limits; missing coverage; original versus derived interpretation |
| QA-PERFORMANCE | A normal dataset, then an appropriately bounded larger retained dataset if available | Actual loading/rendering times, size/record count, hardware/GPU and observed CPU/RAM/network behavior; no synthetic-as-large claims |
| QA-RECOVERY | Restart/reconnect, offline work, cancellation, retry versus Continue | What was retained/reused, holds/consent respected, stale values cleared, no unintended recording/science restart |
| QA-UX | Guided navigation, narrow display, keyboard, high text scaling, language or assistive technology | Screen/language, exact confusing text or clipped control, focus, expected versus observed behavior |

Keep source downloads explicitly approved and bounded. Use disposable copies for deletion/recovery. Never delete your only original. Do not upload original science, location history, credentials or private organization records as routine feedback. The minimal feedback exporter includes only chosen text, build information and an optional reviewed screenshot; sharing remains manual.
