# Scientific interface: short status, details on demand

The five workspaces keep the current task and its next action visible. The existing recording, scientific collection, source verification, research evaluation and organization services still decide what is allowed. Opening an explanation or navigating between workspaces never starts collection or grants permission.

## Three information levels

| Level | Default presentation | Examples and action |
|---|---|---|
| Critical | Visible inline alert with problem, consequence and next action | Stale telemetry during a flight; unavailable collection control state; storage/continuity hold; invalid operating/calibration evidence affecting active collection; required submission minimum missing. Reconnect, review the hold/calibration, or add evidence/save a draft as appropriate. |
| Important | Short, neutral status | Collecting, Armed, Paused; original retained observation count; incomplete repetitions, processing results, missing optional sources. Unknown stays unavailable; it is not converted into a successful measurement. |
| Information | Keyboard-accessible disclosure or existing help | Collection methods, model assumptions, source semantics, advanced payload/transfer settings, exact hashes and reference identities. |

Source identity, original units/dates, actual QA and missing evidence remain with the measurement or result. Permanent deletion still requires the original reviewed, explicit confirmation and refuses active acquisition/import/analysis. Privacy and sharing approval remain explicit, separate from the scientific information levels.

## Where the controls are

- **My Research:** experiment question, source category and **Fly Now / Customize** first. **Requirements & instruments** opens the full method/criteria. **My Templates** contains **Create Template**, custom/multi-point authors and import/export; author forms open only when requested. The survey's three independent measurement choices stay visible.
- **Flight Planner:** selected/recommended instruments are summarized. **Choose instruments & acquisition settings** opens the existing payload selectors; each **Instrument Settings** opens its original cadence, model geometry and calibration. No saved values or unsupported advanced criteria are discarded.
- **Flight Operations:** **Start Recording** is immediately visible before flight. **Recording Options** contains the existing mode and **Arm science** choice. **Science Controls** sits beside the recording controls and shows actions relevant to the current authoritative phase. Collection pause does not pause flight recording. **Collection options & status details** includes the optional pause rationale and automation explanation. **Review a Recorded Flight** holds archive browsing; older results are not shown during a new preparation or active flight. A delayed history read cannot replace the new preparation. The original synchronized timeline keeps **Filter Evidence** and **Accessible Timeline Table** available on demand.
- **Instrument Setup:** actual instrument selection, source, operating/quality status and acquisition state remain accessible. **Collection methods & source types**, **Hyperspectral source preparation**, instrument settings and detailed diagnostics are expandable. A current invalid assessment remains visible outside them.
- **Results & History:** original evidence, units, dates, quality, map/chart/timeline links and saved evaluation remain visible. Interpretation, related tools and exact technical references are optional. Local evaluation remains separate from organization review.
- **Scientific Library:** retained historical sources, actual download/storage state and source identities come first. **Manage Downloaded Data** opens deletion actions; **Advanced — import and source configuration** opens specialist imports. Choosing a source for deletion reveals its management controls. Original destructive confirmations remain unchanged.
- **Organizations:** assignments and submission decisions take priority. **Desktop access** replaces mutually exclusive scope checkboxes with one choice, defaulting to **Read published research**. Trust confirmation and the server's separate browser approval are still mandatory. Upload, own-claim management, live sharing and external Discord consent retain their existing independent boundaries.
- **Submission/review:** exact recipient, selected content/size/time, privacy/retention and explicit approval remain visible. Incomplete required evidence and review blockers appear before any decision; detailed methods/hashes are expandable. No incomplete result becomes a Pass or reviewer approval.
- **Settings:** ordinary scientific network/privacy choices remain visible. **Advanced transfer & source selection** holds finite/unlimited budgets, provider-date selection and concurrency; **Advanced — prepare a small area** holds geographic preparation inputs. Opening either does not enable access or change saved preferences.

The source categories remain distinct: simulator-reported observation, historical scientific dataset, modeled output, pilot observation and unavailable/unsupported input. Synthetic fixtures are labeled separately. Aircraft tracks and source extents are not measured sensor swaths. No new scientific validity or coverage calculation is introduced by this presentation change.

## Validator correction: operations, science and diagnostics

The content hierarchy complements the warning severity levels above. **Operations** shows actual phase, original retained observations or saved-product counts and the next useful action. The main guide contains the original controller's **Start Science Collection**, pause/resume/end and rearm controls; no separate panel is required. A configured automatic Start names its actual waypoint/gate/region condition; manual override still uses the established controller and receipts.

**Sensor Details** holds methods, source/QA, operating conditions and calibration. **Advanced Diagnostics** holds configuration/session identities and original raw reports. Routine unknown metadata is neutral. Actual invalid geometry/calibration, acquisition/source failure and stale control authorization remain visible and actionable. Saved rows, remote products, rejected readings and missing acquisition intervals have different meanings; counts do not establish completion or hardware validity.

For rejected ground geometry, a scientific summary shows unavailable/invalid rather than an enormous raw AGL as a usable intersection. Historic original inputs remain in diagnostics. The source engine refuses the invalid footprint and dependent overlap, while independent valid atmospheric observations and original telemetry are preserved.
