## Implemented foundation

- .NET 10 engine with a self-contained Windows x64 console companion and locally hosted browser dashboard; .NET runtime and SQLite library are included in the preview.
- Explicit simulated telemetry and a native SimConnect telemetry provider, plus a separate CommBus toolbar bridge.
- Named mission start/end, SQLite recording, timestamps and aircraft/source metadata, mission history/details, telemetry JSON access, interrupted-mission recovery and exclusive database ownership.
- Shared mission state and browser SSE updates; the toolbar uses the same mission coordinator through CommBus.
- Universal and Realistic mission modes. Universal is the default; mode is stored in SQLite, retained across restart/migration, and included in shared state/history. Both modes record identically in v0.1.0. Advanced Realistic features are visibly described as future work.
- Aircraft-independent standard telemetry design, including unknown-title/unavailable-data fallbacks. No aircraft whitelist; NASA aircraft are future research examples. Compatibility with individual default, freeware, payware, fixed-wing and rotary-wing aircraft still needs simulator testing.
- Localhost access and optional private-LAN pairing for an iPad/browser, with bounded diagnostic logs and feedback collection.
- Toolbar source for both the read-only diagnostic panel and the full mission UI, with mode selection and mission controls in one responsive interface; plus a separate minimal native-window probe.
- Windows companion build scripts, official-SDK toolbar build/contract checks, package validation, SHA-256 receipts, guarded release packaging, CI, installation/testing instructions and changelog.

Scientific sensors, calibration, data-quality penalties, instrument restrictions, mapping and full replay are not implemented. Timestamped recording/shared-state architecture supports future replay work. There is no tray UI, one-click installer or auto-updater.

## Problems corrected during real SDK testing

- Replaced an incorrect `sizeof(SIMCONNECT_RECV_COMM_BUS) == 32` assumption with checks for the actual field/payload offsets. The fixed header precedes variable-length string data; the payload begins at byte 32.
- Accepted the SDK's three-part `minimum_game_version` (`1.9.18`) as well as four-part versions. Missing/malformed versions remain rejected.
- Matched SDK layout and required-asset paths without regard to letter case. The SDK layout lowercases paths while physical names retain casing such as `ICON_AEROSCIENCE.svg` and `AeroScience.html`. Original files/hashes are preserved; missing files, wrong sizes, duplicate/colliding paths and unsafe paths remain rejected.
- Corrected earlier Windows receipt path separators, launcher defaults/exit handling, SDK tool/header overrides, compiler/package failure handling and runtime diagnostics.
- Replaced unusable cloud-workspace download links with GitHub Actions artifact instructions. **Code → Download ZIP** supplies source, not the executable. Actions artifact downloads require GitHub sign-in and have retention limits.

Do not undo these fixes, fabricate SDK output, or edit generated manifest/layout files to bypass checks.
