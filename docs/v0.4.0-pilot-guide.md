# v0.4.0 pilot walkthrough

Install the Windows Setup EXE when a tested candidate is available. Open AeroScience from Start; it opens the dashboard. Keep your existing Mission Database and Science Library locations on upgrade. Online basemaps and online scientific-data retrieval have separate privacy choices. Choose offline-only if preferred; prepared local sources and saved missions remain usable. No GIS application, Python, handwritten manifest or terminal is needed for supported automatic workflows.

## Plan a multispectral survey

1. Open Mission Planner and create a Geographic Survey. Add a name/objective and draw a modest survey polygon.
2. Enable the multispectral instrument and select **MicaSense RedEdge-P · multispectral**. Reference geometry and its source limitations are visible; this does not turn Sentinel imagery into a RedEdge photograph.
3. In the Flight Pattern Generator choose lawnmower/creeping-line, fit to the survey polygon, and open sensor-based planning. Enter planned **AGL** and **groundspeed**, plus side/forward overlap. Review the recommended spacing, nominal camera GSD, interval and modeled strips. Apply spacing, review the preview and save the plan. Aviation uses NM, feet and knots; Metric converts entered values without moving the route. Pattern heading is true.
4. Review Scientific Data Readiness and prepare the area before takeoff. Wait for validated real coverage and inspect the original dataset date/QA. Missing coverage cannot produce valid observations. The saved scene is historical Earth data.
5. In MSFS load any compatible aircraft, connect the companion and start the selected mission. Fly the intended scan lines manually. Science Collection can pause independently of flight recording. Toolbar controls remain compact; detailed analysis is in the dashboard.
6. End the mission, open Mission History and select Replay. Review actual saved track/acquisitions and gaps. Coverage compares modeled geometric and actual valid source-pixel support; a survey percentage is not inferred without a polygon.
7. In Imagery select NDVI or an available RGB view and **Mission Sample Composite**. Generate, inspect and download the GeoTIFF. Unobserved pixels remain empty. Choose **Retained Source Mosaic** only when you want the independently observed historical source region instead of just recorded samples. Compatible windows of one scene can be joined.
8. Export a Research Package. It includes methods, original source references, timestamps, hashes and derived products. Keep the original Science Library sources for reproduction; the ZIP references rather than duplicates those files.

## Plan a terrain survey

Select **RIEGL VQ-1560 II-S · maximum effective rate**, enter AGL/groundspeed and review the ideal swath/density warnings. Prepare numeric terrain/DSM data. An optional retained terrain source can improve the center-footprint planning preview using relative AGL; otherwise a disclosed flat baseline is used. Fly varied terrain and inspect simulator ground altitude, independent AGL and actual attitude in replay/analysis. External elevation references may not match simulator MSL. The terrain instrument samples genuine DEM/DSM pixels and does **not** generate a real LiDAR point cloud. NOAA LAZ import is not supported in this release.

## Fly an atmospheric mission

Choose Vertical Profile, Cloud Structure Survey or Atmospheric Transect. Set the intended MSL range, ascent/descent/both selection, altitude interval and gap threshold. Enable the actual ambient instruments you need. Fly the climb/descent/transect and review available cloud/visibility/precipitation/ground context. Unsupported simulator variables remain unavailable; they do not stop flight recording. End the mission and open Analysis for profiles, altitude-bin summaries and observed cloud boundaries. Horizontal flight movement and changing weather limit interpretation. A candidate inversion is a local finding, not a regional atmospheric conclusion.

## Review without MSFS

Launch AeroScience normally with MSFS closed. Mission History, Replay, Analysis, local coverage/composite generation and exports remain accessible while their selected archive/source drives are connected. No new scientific downloads occur merely because you replay or build a composite. If an external drive is missing, reconnect it; do not replace the archive with an empty database. Use Collect Feedback for errors and include the operation, source/mission identifiers and displayed status. Keep credentials and private data out of issue reports.
