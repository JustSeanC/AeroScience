### Guarded update/retry after the HDF cancellation failure

An attempt on `4ea0d82` can fail with `The pipe is being closed` in the cancellation test.
The test correctly requires cancellation, not an unclassified IO failure. Use the corrected
source after its hosted Windows check passes. The original failed build has no validation EXE;
keep its folder/logs and do not launch older output from another directory.

Open an x64 Native Tools shell, start PowerShell 7, then paste the **entire block as one unit**.
The repository and existing SDK/authorization paths below match the owner's setup. A failure
exits this block before the launch step. No tests are skipped and no old output is overwritten.

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $PSNativeCommandUseErrorActionPreference = $true
    Set-Location 'C:\Dev\AeroScience-release'
    if (git status --porcelain) { throw 'Preserve local source changes before updating.' }
    git fetch origin
    git switch develop/v0.6.0
    git pull --ff-only origin develop/v0.6.0
    if (git status --porcelain) { throw 'Use a clean committed checkout.' }

    $pythonExe = (python -I -S -c "import sys; print(sys.executable)").Trim()
    if (-not (Test-Path -LiteralPath $pythonExe -PathType Leaf)) { throw 'Actual Python was not found.' }
    $env:Path = (Split-Path -Parent $pythonExe) + ';' + $env:Path
    $validationBuild = 'C:\AeroScience-Builds\Validation060-' + (Get-Date -Format 'yyyyMMdd-HHmmss')
    pwsh -NoProfile -File .\scripts\release\Build-PrivateValidation.ps1 `
        -SdkRoot 'C:\MSFS 2024 SDK' `
        -RuntimeApprovalRecord 'C:\AeroScience-Release-Records\runtime-approval.json' `
        -RuntimeRedistributionConfirmed `
        -OutputDirectory $validationBuild
    if ($LASTEXITCODE -ne 0) { throw 'Build failed. Preserve this new output and logs.' }

    $validationApp = Join-Path $validationBuild 'AeroScience-0.6.0-Validation'
    $validationExe = Join-Path $validationApp 'AeroScience.exe'
    if (-not (Test-Path -LiteralPath $validationExe -PathType Leaf)) { throw 'No completed validation EXE was produced.' }
    python .\scripts\release\private_validation.py verify --folder $validationApp
    if ($LASTEXITCODE -ne 0) { throw 'Private payload verification failed.' }
    Copy-Item .\docs\v0.6.0-acceptance-workbook.md (Join-Path $validationBuild 'OWNER-ACCEPTANCE.md')
    Write-Host "Validation folder: $validationBuild"
    Write-Host "Source: $((git rev-parse HEAD).Trim())"
    Start-Process -FilePath $validationExe
}
```
