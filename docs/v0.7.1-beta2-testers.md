# AeroScience 0.7.1-beta.2 — private tester guide

This private Windows x64 beta contains the v0.7.1 maintenance fixes. Scientific-source
acceptance and installed Windows/MSFS acceptance are **pending**. It is not an approved
production release. The number Beta 2 does not establish that a v0.7.1 Beta 1 was built
or accepted. Use only the exact installer, checksum and source receipt supplied by the owner.

## Install separately

1. Close MSFS and every AeroScience companion, including v0.7.0 Beta 1. The shared
   single-companion mutex remains in force; only one version can run at a time.
2. Verify the SHA-256 of `AeroScience-Setup-v0.7.1-beta.2.exe` against its `.sha256`
   file and `BETA-INSTALLER-RECEIPT.json`. Keep the receipt and installer together.
3. Install into the distinct default directory:
   `%LOCALAPPDATA%\Programs\AeroScience-Beta-v0.7.1-beta.2`.
   Use the **AeroScience 0.7.1-beta.2** Start menu entry. Do not select an existing
   stable, Beta 1, validation, mission or scientific-library directory.
4. Expect a fresh profile in `%LOCALAPPDATA%\AeroScience-Beta-v0.7.1-beta.2`,
   local port **5087**, and an isolated browser cookie. Existing v0.7.0 validation
   data, datasets, settings and organization credentials are not selected or migrated.
   No login credential or scientific original is included in the installer.

The default beta is deliberately empty. Optional archive comparison uses **Copy archives
for validation** in the companion window, with other companions stopped
and backups retained. It copies into this beta's confined root, verifies original hashes,
and disables scientific network access until explicitly approved. Never point Beta 2 at
the live v0.7.0 directories or copy its settings/credentials. Keep the original installation
and archives unchanged; copying does not establish compatibility until actually checked.

## Explicit toolbar switch

Close MSFS before changing Community packages. Beta 2 uses the distinct package
`aeroscience-beta-v0-7-1-beta-2-toolbar` and its own source-bound CommBus namespace.
Simultaneously loading different AeroScience panels has not been accepted in MSFS.
For this private beta, choose one active AeroScience toolbar version explicitly:

- Move older AeroScience toolbar folders, including
  `aeroscience-validation-v0-7-0-toolbar`, from Community into a safe backup folder
  **outside Community**. Preserve their bytes; do not delete them or unrelated add-ons.
- In Beta 2 Settings, explicitly install this build's matching toolbar into the selected
  Community folder. Installation refuses a conflicting enabled AeroScience package.
- Start MSFS and select **AeroScience 0.7.1-beta.2**. Check the exact source identity
  in Connection & Build Details; mismatched toolbars cannot issue commands.
- To return to v0.7.0, close MSFS and Beta 2, move the Beta 2 package outside Community,
  restore the saved v0.7.0 package, and launch the original Beta 1 shortcut.

Setup never switches, removes or installs a Community add-on automatically.

## Maintenance checks and release notes

- Reproduce multispectral preparation with deliberate consent and a small allowance.
  Supported retained STAC envelopes and malformed-candidate fallback are repaired;
  unsupported source/date/QA outcomes remain unavailable. No scientific values are guessed.
- Use **Retry Failed Regions** for failed selected regions. **Continue Preparation**
  separately approves a post-flight hold. Pause, Cancel and Retry retain their distinct
  meanings. Ready verified originals should be reused without another transfer.
- After ending a flight, confirm the prominent approval explanation and complete
  ready/awaiting/unavailable counts. No download should silently resume.
- Check measured MiB/s, active transfer count and actual payload bytes; rates expire
  when transfers stop. Unknown totals remain indeterminate, with no fabricated ETA.
- Check retained terrain at whole-flight, regional and detailed zooms, including zooming
  during initial loading. Dashed acquisition extents are not continuous valid coverage.
  Native values, QA gaps, original hashes and flight-track separation remain intact.
- Recheck native minimum window size, scrolling, saved plans, independent recording/science
  controls, reconnects, offline reopening and exports. Browser tests do not prove MSFS behavior.

Report the full source SHA, installer SHA-256, actual Windows/MSFS versions, relevant
status/error and reproduction steps to the project owner. Review diagnostics before
sharing; they may contain geographic areas. Do not share credentials, signed URLs,
personal archives or original source datasets.

## Uninstall or revert

Uninstall **AeroScience 0.7.1-beta.2** through Windows Installed Apps. Its own application
files and shortcuts are removed. User-owned profiles, missions, scientific archives,
downloaded sources and Community packages remain. The existing v0.7.0 installation,
uninstall entry, shortcuts and archives remain independent. Reinstalling this same beta
does not imply acceptance of its scientific or simulator behavior.
